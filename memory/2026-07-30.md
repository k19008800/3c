# 2026-07-30 — 第5轮迭代：客服工作台增强（§10.1/§27.4）排班/SLA/质检

## 完成内容

### 新增模块：客服排班、SLA 与质检管理（§10.1 增强 / §27.4）

#### DB 迁移：`2026-07-30-staff-schedule.sql`
- **staff_schedules** — 客服排班表（staff_id, weekday, start_time, end_time, is_holiday）
- **staff_schedule_exceptions** — 排班例外（请假/调班/加班，含审批流程）
- **staff_sla_configs** — SLA 配置表（四种工单类型：urgent/high/normal/low，首次响应/解决时间阈值，三级升级通知对象）
- **staff_quality_checks** — 质检记录表（多维评分 JSONB + 总分 + 反馈 + 草稿/发布状态）

#### 后端 API：`routes/admin/support-enhance.ts`（13 个 API）
- **排班管理**：GET/POST schedules（upsert）、DELETE schedule
- **排班例外**：GET/POST schedule-exceptions、POST approve/reject
- **SLA 配置**：GET/POST sla-configs、PUT/DELETE sla-configs
- **质检管理**：GET（分页）/POST/PUT quality-checks

#### 前端页面（2 个新页面）
- **AdminStaffSchedule.tsx** — 排班管理 + SLA 配置
  - 每周七天排班表（时间选择 + 添加/更新/删除）
  - SLA 配置列表 + 新增弹窗（工单类型/响应时间/解决时间/升级策略）
  - 客服 ID 筛选
- **AdminQualityChecks.tsx** — 质检管理
  - 质检记录列表（分数/维度评分/状态标签）
  - 新增/编辑弹窗（多维评分：响应速度/服务态度/准确度/沟通能力/专业度）
  - 分页 + 草稿/发布状态切换

#### 路由注册
- 后端：`app/routes.ts` 导入注册 `adminSupportEnhanceRoutes`
- 前端：`App.tsx` 注册 `admin/support/schedule` + `admin/support/quality`
- Sidebar：客服支持分组下新增「排班管理」「质检管理」入口
