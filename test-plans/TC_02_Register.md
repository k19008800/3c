## 2. 注册模块

### 2.1 正常注册流程

| 编号 | TC-REG-001 |
|------|-----------|
| **测试步骤** | ① 访问 `/register` → ② 输入邮箱、密码(≥6位)、确认密码 → ③ 点击「注册」 |
| **预期结果** | ① 注册成功页显示 CheckCircle2 图标 + "注册成功！" + "即将跳转到登录页面..." → ② 2秒后自动跳转到 `/login` |
| **级别** | L1 |

### 2.2 两次密码不一致

| 编号 | TC-REG-002 |
|------|-----------|
| **测试步骤** | ① 密码输入 `123456`、确认密码输入 `654321` → ② 点击注册 |
| **预期结果** | ① 前端校验：AlertCircle + "两次输入的密码不一致" → ② 不提交请求 |
| **级别** | L1 |

### 2.3 密码长度不足

| 编号 | TC-REG-003 |
|------|-----------|
| **测试步骤** | ① 密码输入 `12345`（5位）→ ② 点击注册 |
| **预期结果** | ① 前端校验：AlertCircle + "密码长度至少为6位" → ② 不提交；或 HTML5 `minLength=6` 阻止提交 |
| **级别** | L2 |
