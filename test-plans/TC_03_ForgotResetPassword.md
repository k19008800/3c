# 忘记/重置密码 — 测试用例

**总用例数：5**

## 3. 忘记/重置密码

### 3.1 忘记密码 — 提交邮箱

| 编号 | TC-FP-001 |
|------|----------|
| **测试步骤** | ① 访问 `/forgot-password` → ② 输入邮箱 → ③ 点击「发送重置链接」 |
| **预期结果** | ① 成功页显示 CheckCircle2 + "邮件已发送" → ② 显示用户输入的邮箱 → ③ "返回登录"按钮 → ④ 无跳转计时器 |
| **级别** | L1 |

### 3.2 忘记密码 — 空邮箱

| 编号 | TC-FP-002 |
|------|----------|
| **测试步骤** | ① 邮箱留空 → ② 点击按钮 |
| **预期结果** | ① HTML5 required 校验阻止 | 
| **级别** | L2 |

### 3.3 重置密码 — 有效 Token

| 编号 | TC-RP-001 |
|------|----------|
| **前置条件** | 从重置邮件获取有效 token |
| **测试步骤** | ① 访问 `/reset-password?token=xxx` → ② 输入新密码(≥6位)、确认密码 → ③ 点击「重置密码」 |
| **预期结果** | ① 成功页显示 CheckCircle2 + "密码已重置" → ② "去登录"按钮链接到 `/login` |
| **级别** | L1 |

### 3.4 重置密码 — 无 Token

| 编号 | TC-RP-002 |
|------|----------|
| **测试步骤** | ① 访问 `/reset-password`（不带 token） |
| **预期结果** | ① AlertCircle + "链接无效" + "请重新申请" + "重新申请"按钮链接到 `/forgot-password` |
| **级别** | L1 |

### 3.5 重置密码 — 表单校验

| 编号 | TC-RP-003 |
