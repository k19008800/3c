# 用户控制台 — 账号安全 — 测试用例

**总用例数：4**

## 14. 用户控制台 — 账号安全

### 14.1 安全评分

| 编号 | TC-SEC-U-001 |
|------|-----------|
| **测试步骤** | ① 访问 `/console/security` |
| **预期结果** | ① 安全评分卡片：基于活跃会话数+失败登录率 自动计算→ 安全(绿)/注意(琥珀)/风险(红) → ② 评分逻辑参数显示（活跃会话数/其他设备数/失败登录次数）→ ③ 登录城市标签展示 |
| **级别** | L1 |

### 14.2 活跃会话

| 编号 | TC-SEC-U-002 |
|------|-----------|
| **测试步骤** | ① 查看"活跃会话"区块 |
| **预期结果** | ① 当前设备标注"当前设备"蓝色标签 → ② 其他设备显示位置+IP+最后活跃时间 → ③ 每个非当前设备有「下线」按钮 → ④ 多于1个设备时"下线其他设备"按钮可用 → ⑤ 下线后该会话从列表移除 |
| **级别** | L1 |

### 14.3 登录历史

| 编号 | TC-SEC-U-003 |
|------|-----------|
| **测试步骤** | ① 查看"最近登录记录"区块 |
| **预期结果** | ① 表格：结果(CheckCircle2/XCircle)/时间/IP/地点/设备 → ② 成功绿色图标/失败红色图标 → ③ 空数据展示"暂无登录记录" |
| **级别** | L1 |

### 14.4 刷新

| 编号 | TC-SEC-U-004 |
|------|-----------|
| **测试步骤** | ① 点击评分卡片右上角「刷新」 |
| **预期结果** | ① 重新获取安全数据 → ② 评分和会话列表刷新 |
| **级别** | L2 |
