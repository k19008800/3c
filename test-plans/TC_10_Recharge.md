# 用户控制台 — 充值 — 测试用例

**总用例数：6**

---

## 10. 用户控制台 — 充值

### 10.1 Tab 切换

| 编号 | TC-RECHARGE-001 |
|------|---------------|
| **测试步骤** | ① 访问 `/console/recharge` |
| **预期结果** | ① 三个 Tab：在线支付/银行转账/充值记录 → ② 默认选中"在线支付" → ③ Tab 切换内容刷新 |
| **级别** | L1 |

### 10.2 在线支付流程

| 编号 | TC-RECHARGE-002 |
|------|---------------|
| **测试步骤** | ① 选择预设金额 → ② 选择支付渠道（微信/支付宝）→ ③ 点击「立即支付」 |
| **预期结果** | ① 订单创建成功 → ② 显示支付二维码 → ③ 扫码支付后状态自动更新 → ④ 跳转到充值记录页 |
| **级别** | L1 |

### 10.3 银行转账表单

| 编号 | TC-RECHARGE-003 |
|------|---------------|
| **测试步骤** | ① 切换到"银行转账"Tab |
| **预期结果** | ① 展示银行账户信息 → ② 输入：金额/银行名称/银行卡号/转账日期/用户备注 → ③ 支持上传凭证图片 → ④ 提交后显示"审核中"琥珀色标识 |
| **级别** | L1 |

### 10.4 充值记录

| 编号 | TC-RECHARGE-004 |
|------|---------------|
| **测试步骤** | ① 切换到"充值记录"Tab |
| **预期结果** | ① 分页列表展示历史充值订单 → ② 每行：金额/渠道/状态/时间 → ③ 状态标签：待支付/已支付/已确认/已过期 → ④ 支持按状态筛选 |
| **级别** | L1 |

### 10.5 模拟模式阻断

| 编号 | TC-RECHARGE-005 |
|------|---------------|

| **级别** | L2 |
