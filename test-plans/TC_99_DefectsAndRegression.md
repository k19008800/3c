## 29. UI 缺陷记录与整改方案

### 29.1 已知缺陷

| 序号 | 模块 | 缺陷描述 | 严重度 | 整改方案 |
|------|------|---------|--------|---------|
| BUG-001 | API 密钥 | 当密钥数量>10时，表格无虚拟滚动，长列表性能下降 | 中 | 添加行虚拟滚动或分页，默认每页20条 |
| BUG-002 | 登录 | 密码错误提示未能统一（可能泄露"用户不存在"vs"密码错误"的差异） | 高 | 检查后端返回 message，统一为"邮箱或密码错误" |
| BUG-003 | 设置-通知 | 通知偏好 PUT 接口可能未实现，返回404时仍使用默认值 | 中 | 确认 API 端点 `PUT /api/v1/preferences/notifications` 实现状态 |
| BUG-004 | 侧边栏 | 折叠状态未持久化（关闭页面后恢复展开） | 低 | 使用 localStorage 保存 `sidebarCollapsed` 状态 |
| BUG-005 | 全局 | 部分页面标题缺失或无浏览器 tab 标题 | 低 | 添加 `document.title` 设置，每个页面设置对应标题 |
| BUG-006 | 限流管理 | RPM/TPM 只设其一不显示（AND→OR 条件已修复，验证稳定性） | 中 | 验证修复后单体条件过滤依然正确 |
| BUG-007 | 充值审核弹窗 | 历史版本存在盲审问题（银行信息不显示），已修复弹窗展示 | 高 | 回归验证：审核弹窗展示银行名/账号后缀/转账日期/用户备注/凭证图片 |
| BUG-008 | 供应商管理 | modelCount bigint→Number 拼接 bug（已修复） | 中 | 验证大模型数场景下显示不溢出 |
| BUG-009 | Vite Proxy | `/api` 前缀匹配拦截 `/api-keys` SPA 路由（已修复为 `/api/`） | 高 | 回归验证：直接访问 API Keys 页面正常，API 请求正常 |
| BUG-010 | 管理角色编辑 | setByRole 显示修复（admin 修改后身份未更新） | 高 | 回归验证：admin 修改其他用户角色后身份卡片刷新 |
| BUG-011 | 登录 Loading | 登录按钮在请求未完成时可重复点击（disabled 应在请求开始即设置） | 中 | 确认 `setLoading(true)` 在 `try` 之前调用 |
| BUG-012 | 全局 401 处理 | 并发请求多个 401 时触发多次登出跳转 | 中 | api.ts 拦截器中增加防重入锁，只跳转一次 |
| BUG-013 | 全局 401 处理 | 401 拦截器未排除公开 API，导致登录页陷入 `/login` 无限循环（**2026-07-31 已修复**） | 🔴严重 | 在 skipAuthReset 列表增加 me/settings / wechat-login / auth/refresh / site-config；跳转前检查是否已在登录页 |
| BUG-014 | 登录页 | 登录按钮在表单为空时缺少 disabled 视觉反馈 | 中 | 添加 `disabled={loading || !email || !password}` 条件 |
| BUG-015 | 门户首页 | 统计数据显示 "undefined+ 累计处理 Token" | 中 | 修复 Portal Home 组件中 formatNumber 传入 undefined 问题 |
| BUG-016 | 后端模型管理 | GET /api/v1/admin/models 返回 500（`models` 表缺失） | 🔴严重 | 执行数据库 migration 创建 models 表 |
| BUG-017 | 后端安全配置 | GET /api/v1/admin/security/config 返回 500（`login_security_configs` 表缺失） | 🔴严重 | 执行数据库 migration 创建 login_security_configs 表 |
| BUG-018 | 后端路由 | 8 个 API 返回 404（限流/监控/告警/演练/汇率/日志趋势等） | 🔴严重 | 补充缺失的后端路由注册 |

## 30. 回归测试步骤

### 30.1 缺陷修复后回归验证清单

```
□ BUG-001 密钥长列表性能：
  验证步骤：创建20+密钥 → 检查页面滚动卡顿

□ BUG-002 登录错误统一：
  验证步骤：分别测试不存在邮箱 + 错误密码 → 两次提示文案应一致

□ BUG-003 通知偏好保存：
  验证步骤：修改任意开关 → 保存 → 刷新页面 → 偏好应保持

□ BUG-004 侧边栏折叠持久化：
  验证步骤：折叠侧边栏 → F5刷新 → 应保持折叠状态

□ BUG-005 页面标题：
  验证步骤：逐个页面检查浏览器 Tab 标题

□ BUG-006 限流条件过滤：
  验证步骤：创建 RPM/TPM 只有其一 → 列表应显示该规则

□ BUG-007 充值审核弹窗：
  验证步骤：提交流程 → 管理员审核弹窗应展示完整银行信息

□ BUG-008 模型数显示：
  验证步骤：查看供应商列表 >50 模型的供应商 → modelCount 显示正确

□ BUG-009 Vite Proxy：
  验证步骤：登录后 → 点击"API 密钥"侧边栏 → 页面正常渲染（非404）

□ BUG-010 角色更新：
  验证步骤：admin 修改用户角色 → 用户个人信息卡片刷新

□ BUG-011 防重复提交：
  验证步骤：慢速网络下点击登录 → 按钮立即 disabled

□ BUG-012 401防重入：
  验证步骤：让 token 过期 → 发起多个请求 → 只跳转一次登录页

□ BUG-013（2026-07-31 已修复）401 无限循环：
  验证步骤：清除 localStorage → 访问 /login → 应正常显示登录表单（非无限 Loading）
  验证步骤：未登录状态直接访问 /console → 应重定向到 /login

□ BUG-014 登录按钮 disabled：
  验证步骤：邮箱和密码均为空 → 按钮应有 disabled 样式（灰色不可点击）
  验证步骤：填写任一字段 → 按钮恢复可点击

□ BUG-015 门户首页 "undefined+ Token"：
  验证步骤：访问首页 → 累计处理 Token 行应显示有效数字而非 undefined

□ BUG-016~018 后端 API 缺失：
  验证步骤（执行 migration 后）：
  - GET /api/v1/admin/models?page=1&pageSize=20 → 返回200
  - GET /api/v1/admin/security/config → 返回200
  - 模型管理页面 → 正常显示模型列表
  - 安全配置页面 → 正常显示配置项
```
