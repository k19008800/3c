# 用户/代理商/业务员/渠道需求原子审计说明

- 审计范围：用户端、代理商端、业务员端、渠道端相关 PRD/SPEC/ref 文档；基线统计见 `audit/00-baseline/baseline-summary.json`（requirements_docs=420、api_registered=479、frontend_call_sites=469、test_files=80）。
- 输出：`user-agent-atomic.csv`，共 **104 条**原子断言（UA-0001～UA-0104）。每条包含单一可验证断言、原文摘录、来源路径、章节、优先级、类别。
- 本阶段只记录需求，不判定实现代码 PASS/FAIL；没有把实现现状当成通过结论。
- 维度覆盖：输入、前置、角色、权限、状态、正常、边界、异常、并发、幂等、事务、回滚、落库、缓存、通知、审计、监控、帮助与测试相关可验证要求。并发/幂等/测试在指定涉众文档中显式要求较少，未凭空补充实现结论；原子表中的幂等/并发项仅在原文明确可验证时记录。
- 重要原文要求：
  - `docs/PRODUCT-DESIGN-PRINCIPLES.md` P1 要求所有页面标题及操作入口提供 `[?]` 帮助；P3 要求批量预览、二次确认、审计、错误报告；P4 要求 loading、空态、错误重试、进度及结果反馈。
  - 用户 Key 明文不得落库，仅存 bcrypt hash，创建时一次展示；删除不可恢复。
  - 渠道选择采用 `model@channelCode`，未选渠道自动智能路由；用户响应不得暴露渠道成本价；维护/下架渠道回退自动路由。
- 说明：源文件 PowerShell 检索时部分中文显示为乱码，但 CSV 摘录直接以 UTF-8 保存，路径与章节按源文档核对。
