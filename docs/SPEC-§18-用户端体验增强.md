## 18.1 API 在线调试工具

### 功能描述

用户在浏览器内选择模型、填写参数、发起 API 调用，实时查看返回结果，无需写代码。

### 完成能力 / 展示效果

用户在控制台进入"API Playground"：
- 选择模型（下拉框，展示可用模型列表）
- 填写参数（Messages / Temperature / Max Tokens / Top P 等）
- 发起调用 → 实时展示响应内容 + Token 消耗 + 耗时 + 费用
- 失败时展示错误信息
- 一键复制 cURL 命令 / Python 代码
- 调用历史：查看之前调试的请求/响应记录

### 上下游关系

```
用户填写参数 → 调用代理 API → 返回结果 → 展示详情
（走的是正常计费流程，调试也扣费）
```

## 18.2 用量预算控制

### 功能描述

用户设置预算上限，接近/达到时自动告警或停止调用，防止意外超额消费。

### 完成能力 / 展示效果

- **预算设置**：月度预算 / 日预算 / 单 Key 预算
- **告警阈值**：达到 50%/80%/90% 时自动通知
- **超限动作**：仅告警 / 停止新调用 / 降级到低成本模型
- **预算看板**：当前进度（预算使用百分比进度条）/ 预估日消费 / 预估月消费
- **超额追溯**：触发超限时的调用记录

## 18.3 用户引导（Onboarding）

### 功能描述

新用户注册后分步引导完成首次 API 调用，降低上手门槛。

### 完成能力 / 展示效果

引导流程（步骤条）：
1. ✅ 注册完成
2. ➡️ 创建 API Key（自动跳转到 Key 创建页）
3. ⏳ 首次调用（引导到 Playground 或展示 cURL 示例）
4. ⏳ 查看日志（引导到调用日志页）

每步完成自动打勾，未完成提示"下一步"
新手保护期（注册后前 7 天）展示在欢迎卡片中

## 18.4 账单与消费分析

### 功能描述

用户查看月度账单和消费分析图表，了解消费构成和趋势。

### 完成能力 / 展示效果

- **月度账单**：月度消费总额 + 每日消费趋势
- **模型分布**：各模型消费占比饼图
- **每日消费详情**：可点击某天查看该日的消费明细
- **账单下载**：PDF 格式账单
- **对比**：本月 vs 上月 消费对比
- **成本优化建议**：基于使用模式推荐低成本替代模型

## 18.5 通知偏好管理

### 功能描述

用户自定义各类通知的推送方式和开关。

### 完成能力 / 展示效果

- **通知分类**：充值成功 / 余额预警 / Key 过期 / 安全告警 / 活动通知 / 公告

## 18.6 账号安全中心

### 功能描述

用户管理账户安全设置，包括密码修改、登录记录、设备管理、双因素认证。

### 完成能力 / 展示效果

- **密码修改**：输入旧密码 → 新密码（密码强度检测）
- **登录记录**：最近登录列表（时间/IP/归属地/设备），异常登录标红
- **设备管理**：查看已登录设备，支持远程登出
- **双因素认证**（P1）：开启/关闭 2FA，绑定认证器

## 18.8 官方 SDK 与多语言支持

### 功能描述

提供官方 SDK（Python / Node.js / Java / Go / Rust），降低开发者的接入成本。

### 完成能力 / 展示效果

**支持的语言：**
- 🐍 Python：`pip install 3cloud-sdk` — 最成熟，示例最丰富
- 💚 Node.js / TypeScript：`npm install 3cloud-sdk` — 类型定义完整
- ☕ Java：`mvn install com.unmisa:3cloud-sdk` — 支持 Spring Boot 集成
- 🔵 Go：`go get github.com/3cloud/go-sdk` — 轻量，适合微服务
- 🦀 Rust：`cargo add 3cloud-sdk` — 高性能场景

**SDK 自动处理：**
  - 认证头注入：自动读取环境变量 `THREECLOUD_API_KEY`
  - 自动重试：可配置重试次数（默认 3 次）和退避策略
  - 错误解析：将 HTTP 响应自动转为结构化异常
  - 超时控制：默认 60s 超时
  - 类型安全：TypeScript / Java 类型定义完整

**文档：**
- 各语言 SDK 的 README 包含：安装 → 初始化 → 基础调用 → 流式调用 → 错误处理
- GitHub/GitLab 发布，按语义化版本管理
- Changelog 记录每个版本的变更

**Quick Start 代码示例（开发者文档中可直接复制）：**
```python
from threecloud import ThreeCloud

client = ThreeCloud(api_key="sk-3c-xxx")
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
```

## 边界条件

| # | 场景 | 触发条件 | 预期行为 |
|---|------|---------|---------|
| UX-001 | API Playground 调用金额超预算 | 用户在 Playground 调试时发起的大模型调用费用超过其预算上限 | 调用被预算拦截器阻止，前端展示"该调用将超出预算上限，请在预算设置中调整"，不发起实际请求 |
| UX-002 | 预算告警阈值触发后继续消费 | 用户预算达到 90% 告警阈值后仍继续调用至 100% | 按用户预设的超限动作执行：仅告警模式继续放行，停止模式拒绝新调用，降级模式切换到低成本模型 |
| UX-003 | Onboarding 步骤未完成 | 新用户注册后 7 天新手保护期内未完成所有引导步骤（如未创建 Key/未发起首次调用） | 首页持续展示引导条，每次登录提示未完成步骤，第 7 天后引导条自动收起到通知中心 |
| UX-004 | 2FA 绑定中断 | 用户在 2FA 绑定流程中刷新页面或关闭浏览器，未完成绑定 | 重新进入安全中心时检测到绑定未完成，提示"上次 2FA 绑定未完成"，允许继续或重新开始 |
| UX-005 | SDK 自动重试耗尽 | SDK 默认重试 3 次后所有尝试均因服务端错误而失败 | 抛出结构化的 MaxRetryExceededException，包含前三次的详细错误列表，客户端根据异常类型决定是否继续降级 |
| UX-006 | 公开状态页数据源故障 | 公开 API 状态页的数据采集模块本身出现故障，无法获取服务状态 | 状态页展示"数据采集中断"提示，使用上一次缓存的健康数据继续展示，历史 uptime 不受影响 |
