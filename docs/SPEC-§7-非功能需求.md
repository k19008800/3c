### 功能描述

平台非功能需求覆盖性能、可用性、安全、可扩展性、兼容性、可维护性、数据合规 7 个维度。所有指标均有明确目标和当前状态验证。

### 完成能力

**性能指标：**

| 指标 | 目标 P95 | 当前状态 |
|------|---------|---------|
| 简单查询（单表/主键） | < 100ms | ✅ 已达标 |
| 列表分页（含筛选） | < 200ms | ✅ 已达标 |
| 复杂聚合（统计/趋势） | < 500ms | ✅ 已达标 |
| 模糊搜索（ILIKE） | < 100ms | ✅ 已达标 |
| 日志查询（分区表） | < 1s | ✅ 已达标 |
| 批量操作（万级） | < 3s | ✅ 已达标 |
| API 并发 | 1000+ QPS | ✅ 经四级限流保护 |

**可用性**：单机部署，PM2 cluster 自动重启，供应商故障自动熔断切换

**安全**：HTTP Only Cookie 鉴权、bcrypt API Key hash、CORS 配置、IP 黑白名单、2FA

**可扩展性**：API 无状态设计，数据库水平扩展预留（读写分离），前端组件化

**兼容性**：兼容 OpenAI API 格式，零代码迁移

**可维护性**：代码风格统一（DrizzleORM + Fastify + TypeScript），组件拆分完成

**数据合规**：个人电话脱敏、证件号脱敏、操作日志可审计、数据保留策略可配置

### [?] 页面帮助

**页面名称**：非功能需求

**适用角色**：所有开发和运维人员

**功能定位**：定义平台非功能需求基线：性能、可用性、安全、可扩展性、兼容性、可维护性、数据合规 7 个维度，所有指标均有明确目标和验证状态。

**子模块说明**：
- §7.1 性能：响应时间、吞吐量、并发目标
- §7.2 可用性：SLA 目标、故障恢复时间
- §7.3 安全：认证/授权/数据加密/安全审计要求
- §7.4 可扩展性：水平扩展、容量规划
- §7.5 兼容性：浏览器/API 版本兼容
- §7.6 可维护性：日志/监控/文档要求
- §7.7 数据合规：数据留存/隐私/合规要求

**注意事项**：
- 性能指标以压测报告为准，验收时需提供验证数据
- 安全要求为硬性指标，不满足不得上线
- 数据合规要求随法规更新，需定期review

**常见问题**：
Q: 性能指标如何验证？
A: 通过压测工具（如 k6/JMeter）生成测试报告，与目标指标对比验收。

Q: 安全合规检查多久做一次？
A: 上线前必须做安全评审，日常通过自动化扫描持续检查。
