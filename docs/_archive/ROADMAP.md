## 下一步规划（Post-P2）

按优先级从高到低排列：

### 🔴 P1（高优先级）

#### 1. 子账号/团队管理
| 项 | 说明 |
|---|------|
| **问题** | 企业用户无法创建子账号共享额度/Key |
| **历史** | 曾移除团队管理功能（ADR-2026-07-11），因为与核心计费未打通 |
| **方案** | 重新设计：企业主账号 → 子账号（共享额度池 / 独立计费两种模式） |
| **依赖** | 用户模型扩展、角色权限扩展、额度分配逻辑 |
| **关联模块** | Users 表、Roles 表、API Key 权限、前端用户管理页面 |
| **预估** | ~5 天（设计 1d + 后端 2d + 前端 2d） |

#### 2. 全局搜索
| 项 | 说明 |
|---|------|
| **问题** | 管理员在 50+ 页面中查找信息效率低 |
| **现状** | 已有 SearchModal 组件框架（`components/layout/SearchModal.tsx`） |
| **方案** | 扩展 SearchModal 跨模块搜索：用户/Key/订单/供应商/日志/配置 |
| **依赖** | 搜索后端统一接口、索引策略 |
| **预估** | ~3 天 |

#### 3. 工单/客服系统
| 项 | 说明 |
|---|------|
| **问题** | 用户遇到问题只能发邮件，无工单追踪流程 |
| **方案** | 用户提交工单 → 管理员处理 → 用户确认关闭 |
| **关联模块** | 通知系统、邮件服务、管理后台新页面 |
| **预估** | ~3 天 |

---

### 🟡 P2（中优先级）

#### 4. 余额/消费明细流水增强
| 项 | 说明 |
|---|------|
| **问题** | 用户无法按时间范围/分类筛选消费明细 |
| **现状** | 有 transactions 页面但筛选粒度不足 |
| **方案** | 扩展筛选维度、增加 CSV 导出、余额变动日历视图 |
| **预估** | ~2 天 |

#### 5. 英文国际化（i18n）
| 项 | 说明 |
|---|------|
| **问题** | 只有中文界面，海外用户无法使用 |
| **方案** | React i18next + 后端多语言响应 |
| **备注** | 工程量大。建议先做前端关键页面（登录/注册/API Key/文档） |
| **预估** | ~10 天（全量） / ~3 天（MVP） |

#### 6. 移动端适配
| 项 | 说明 |
|---|------|
| **问题** | 桌面版为主，移动端体验差 |
| **方案** | 响应式适配关键页面（仪表盘/Key管理/日志）或独立 H5 |
| **预估** | ~5 天（响应式） / ~10 天（独立 H5） |

---

### 🔵 P3（低优先级 / 探索性）

#### 7. API 文档自动生成
| 项 | 说明 |
|---|------|
| **问题** | 开发者文档需手动维护，容易落后代码 |
| **方案** | 接入 OpenAPI/Swagger，基于路由定义自动生成 |
| **预估** | ~2 天 |

#### 8. 更多供应商接入
| 项 | 说明 |
|---|------|
| **问题** | 供应商越多平台价值越大 |
| **现状** | 已对接 DeepSeek / OpenAI / Anthropic / OspreyAI / LLMRouter / 天翼云 |
| **方向** | 持续扩展，按用户需求优先级接入 |

#### 9. 数据看板增强
| 项 | 说明 |
|---|------|
| **方案** | 自定义仪表盘（拖拽组件）、大屏模式、定时报表邮件推送 |
| **预估** | ~5 天 |

#### 10. SEO 优化（门户）
| 项 | 说明 |
|---|------|
| **问题** | Portal 官网 SEO 基础弱 |
| **方案** | SSR 优化、meta 标签完善、结构化数据、sitemap |
| **预估** | ~3 天 |

---

## 长期方向

| 方向 | 说明 |
|------|------|
| **模型中转 API 标准化** | 兼容 OpenAI 协议作为标准，降低用户迁移成本（已支持） |
| **用量预警/自动充值** | 余额低于阈值自动从绑定支付方式扣款 |
| **企业 SSO 集成** | LDAP/OIDC/SAML 企业登录集成 |
| **插件/扩展市场** | 允许第三方开发插件扩展平台能力 |
| **API 访问日志分析** | 基于 AI 的调用异常检测与优化建议（已有行为分析基础） |
