### 功能描述

平台与第三方系统的集成方案，包括支付网关、短信服务、对象存储、故障切换策略等。

### 完成能力

**16.1 第三方服务总览：**

| 系统 | 用途 | 状态 | 集成方式 |
|------|------|------|---------|
| 支付宝/微信支付 | 用户充值 | ✅ 已完成 | 支付回调 webhook |
| SMTP 邮件服务 | 通知推送 | ✅ 已完成 | 异步队列消费 |
| WebSocket | 实时推送 | ✅ 已完成 | 在线用户/告警推送 |
| 电子签章（法大大/上上签）| 合同签署 | 📋 P1 | API 对接 |
| 短信服务（阿里云/腾讯云）| 重要告警短信 | 📋 P1 | API 对接 |
| 对象存储（OSS/S3）| 文件/头像/合同存储 | 📋 P1 | SDK 集成 |
| 企业微信/钉钉 | 运营报表推送 | 📋 P2 | Webhook |
| IP 地理库 | IP 归属地解析 | ✅ 已完成 | 本地库/API |

**16.2 支付网关集成：**
- 支持支付宝和微信支付
- 配置项：APP ID、商户号、API Key、回调 URL
- 回调处理：异步接收支付结果 → 更新订单状态 → 通知用户
- 掉单处理：定时查询未完成订单状态

**16.3 短信服务集成：**
- 发送场景：验证码、重要告警通知
- 模板化管理：在平台后台创建短信模板
- 发送频率限制：同一手机号每分钟最多 1 条

**16.4 对象存储集成：**
- 用途：用户头像、合同文件、证书照片
- 配置：Bucket/Region/AccessKey/SecretKey
- 权限控制：仅平台后台可写，通过签名 URL 可读

**16.5 故障切换策略：**
- 第三方服务故障 → 记录错误日志 + 告警通知
- 支付网关故障 → 标记订单"充值中"，定时重查
- 短信故障 → 降级为邮件通知
- 所有第三方调用通过 adapter 模式封装，替换实现无需修改业务代码
