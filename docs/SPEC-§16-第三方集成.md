### 功能描述

平台与第三方系统的集成方案，包括支付网关、短信服务、对象存储、故障切换策略等。

### 完成能力

**16.1 第三方服务总览：**

| 系统 | 用途 | 状态 | 集成方式 |
|------|------|------|---------|
| 支付宝/微信支付 | 用户充值 | ✅ 已完成 | 支付回调 webhook |
| SMTP 邮件服务 | 通知推送 | ✅ 已完成 | 异步队列消费 |
| WebSocket | 实时推送 | ✅ 已完成 | 在线用户/告警推送 |
| 电子签章（法大大/上上签）| 合同签署 | 📋 P1 | API 对接 |
| 短信服务（阿里云/腾讯云）| 重要告警短信 | 📋 P1 | API 对接 |
| 对象存储（OSS/S3）| 文件/头像/合同存储 | 📋 P1 | SDK 集成 |
| 企业微信/钉钉 | 运营报表推送 | 📋 P2 | Webhook |
| IP 地理库 | IP 归属地解析 | ✅ 已完成 | 本地库/API |

**16.2 支付网关集成：**
- 支持支付宝和微信支付
- 配置项：APP ID、商户号、API Key、回调 URL
- 回调处理：异步接收支付结果 → 更新订单状态 → 通知用户
- 掉单处理：定时查询未完成订单状态

**16.3 短信服务集成：**
- 发送场景：验证码、重要告警通知
- 模板化管理：在平台后台创建短信模板
- 发送频率限制：同一手机号每分钟最多 1 条

**16.4 对象存储集成：**
- 用途：用户头像、合同文件、证书照片
- 配置：Bucket/Region/AccessKey/SecretKey
- 权限控制：仅平台后台可写，通过签名 URL 可读

**16.5 故障切换策略：**
- 第三方服务故障 → 记录错误日志 + 告警通知
- 支付网关故障 → 标记订单"充值中"，定时重查
- 短信故障 → 降级为邮件通知
- 所有第三方调用通过 adapter 模式封装，替换实现无需修改业务代码

## 边界条件

| # | 场景 | 触发条件 | 预期行为 |
|---|------|---------|---------|
| THIRD-001 | 第三方 API 限流 | 短时内调用次数超过第三方服务商限流阈值（如支付网关 QPS > 100） | 采用本地令牌桶限流，超过阈值的请求排队等待或降级为异步处理，记录限流日志 |
| THIRD-002 | 支付回调超时 | 用户完成支付后，第三方支付网关回调接口超过配置超时（默认 30s）未响应 | 定时任务轮询未完成订单（每 2 分钟），调用第三方对账接口确认支付状态 |
| THIRD-003 | Webhook 重试耗尽 | 第三方 Webhook 推送失败后重试 3 次仍失败 | 标记 Webhook 为"死信"状态，持久化到死信队列，触发人工介入告警，支持手动重推 |
| THIRD-004 | 短信服务商切换 | 主短信服务商故障后自动切换到备选服务商 | 通过 adapter 模式无缝切换，切换期间请求排队等待（最长 5s），切换完成后自动恢复 |
| THIRD-005 | OSS 签名 URL 过期 | 用户通过已过期的签名 URL 访问存储文件 | 返回 403 Forbidden，前端引导用户重新获取签名 URL |
| THIRD-006 | 第三方凭证变更未同步 | 运营人员在第三方平台更换了 API Key/Secret，但未同步更新到 3cloud 配置 | 集成健康检查模块定时验证第三方凭证有效性，发现失效后发送告警通知 |
