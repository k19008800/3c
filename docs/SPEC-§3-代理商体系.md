## 3.1 代理商层级与权益

### 功能描述

平台支持代理商等级体系（预备→一级→高级），每级有不同的准入条件、权益和佣金率。等级由后台设定（无自助注册/升级，单级分销，无子代理，见后台主导版）。

### 完成能力 / 展示效果

**代理端：**
- ~~预备代理注册后，在代理端看到自己的等级和权益说明~~（已移除：代理商由后台「设为代理商」创建，无自助注册）
- 等级由后台设定，权益说明在代理端可见
- 高级代理可见阶梯佣金率和专属权益（客户经理、优先支持）

**管理后台（代理管理→代理等级）：**
- 代理晋级审核待办列表：姓名/当前等级/申请等级/申请时间/资质材料
- 审核操作：通过/驳回（需填写原因）
- 审核通过后代理等级即时变更，佣金规则自动切换

### 上下游关系

```
后台管理员 → 「设为代理商」（选等级 + 佣金档位）→ 代理商身份创建
   ↓
代理商等级/佣金档位：仅后台可调整（无自助升级）
   ↓
预备代理：仅查看规则，不可提现
一级代理：全功能面板、自定义佣金、可提现
高级代理：阶梯佣金 12-18%、专享权益
（单级分销：无子代理层级，D1）
```

### 边界条件

| 场景 | 行为 |
|------|------|
| ~~预备代理申请升级时资料不全~~ | ~~管理端审核时标注"资料不完整"，驳回并填写需要补充的材料~~（已移除：无自助升级，等级由后台直接设定） |
| 代理降级 | 连续 3 个月消费未达标，系统自动降级（可配置）；等级变更只影响之后产生的佣金 |
| ~~子代理升级为一代理~~ | ~~需脱离上级代理，独立申请审核~~（已移除：D1 单级，无子代理） |

## 3.2 佣金规则配置

### 功能描述

管理员可精确配置每个代理的佣金规则，支持阶梯比例、固定金额、混合模式。所有规则变更留审计日志。

### 完成能力 / 展示效果

**管理后台：**
- 选择代理 → 配置佣金规则
- 选择计算方式：固定比例 / 阶梯比例 / 固定金额 / 混合
- 阶梯比例可添加多条：月消费 ¥0-1000→5%、¥1000-5000→8%、¥5000+→12%
- 混合模式按不同模型设置不同佣金率（如 GPT-4o 5%、DeepSeek 3%）
- 保存前预览效果：输入预估月消费，系统模拟佣金金额
- 选择生效时间：立即生效 / 下个结算周期生效

**展示效果：**
- 每个代理详情页中展示当前佣金规则
- 规则变更历史可追溯（修改前值→修改后值→操作人→时间）
- 可选"追溯至本月 1 日"（已有消费按新规则计算佣金）

### 上下游关系

```
上游：管理员配置 → 写入佣金规则 + 写入 audit 日志
      佣金计算引擎 → 读取规则 → 按「消费时刻归属」解析归属客户消费对应的佣金（单级）
下游：佣金计算结果 → 写入 agent_commissions（实时 settled）
      结算模块 → 读取佣金日志 → 生成结算单
```

## 3.3 代理端仪表盘

### 功能描述

代理商登录后看到专属仪表盘，6 张 KPI 卡片 + 趋势图，实时掌握名下客户和收益情况。

### 完成能力 / 展示效果

代理商在代理端首页看到：

| 指标卡片 | 展示内容 |
|---------|---------|
| 总客户数 | 名下总用户数 + 本月新增数 |
| 月新增客户 | 当月新注册并调用的用户数 |
| 月消费 | 名下用户当月总消费金额（¥） |
| 月佣金收入 | 当月产生的佣金金额 |
| 待结算金额 | 已产生但未结算的佣金总额 |
| 佣金率 | 当前平均佣金率 |

趋势图（近 7 天/近 30 天）：
- 名下用户消费趋势（折线图）
- 佣金收入趋势（折线图）
- 客户增长趋势（柱状图）

### 上下游关系

```
数据来源：
  agent_customer_bindings 表（status=active）→ 归属客户数
  consumption_records 表 → 月消费总额（归属客户）
  agent_commissions 表 → 佣金收入
  agents.available_balance → 可提现/待结算余额
```

## 3.4 提现管理

### 功能描述

代理商申请将佣金提现到个人账户，支持双审流程（财务初审 + 运营复审），确保资金安全。

### 完成能力 / 展示效果

**代理端（发起提现）：**
- 查看可提现余额、冻结余额
- 输入提现金额 → 选择到账方式（银行卡/支付宝/微信）→ 填写账户信息
- 系统校验：金额 ≤ 可提现余额、提现频率符合限制（每 24h 最多 1 次）
- 提交后显示提现单号，状态为"审核中"

**管理后台（提现审核）：**
- **待初审列表**（finance 角色可见）：
  - 展示代理信息：名称、等级、注册时间、总交易量
  - 账户情况：余额、可提现、冻结金额
  - 提现历史：已完成 N 笔，总额 ¥X
  - 本次提现：金额、到账方式、账户
  - 近 7 天消费：是否异常（消费下降趋势标注提醒）
  - 操作：[通过] [驳回 - 填写原因]
- **待复审列表**（admin/agent_mgr 角色可见）：
  - 初筛通过后的提现请求，展示初审意见
  - 操作：[确认打款] [驳回]
- **复审通过后** → 财务打款 → 打款完成 → 通知代理

### 上下游关系

```
代理发起提现 → 校验规则（金额/频率/冻结期）
  ↓ 通过
待初审列表（finance 角色）→ 初审通过
  ↓
待复审列表（admin/agent_mgr）→ 复审通过
  ↓
财务打款（线下或自动转账）→ 标记完成
  ↓
通知代理：提现已到账
```

### 提现约束

| 限制项 | 规则 |
|-------|------|
| 最低提现金额 | ¥10（可配置）|
| 最高提现金额 | 可提现余额（不可超过）|
| 提现频率 | 每 24 小时最多 1 次（可配置）|
| 冻结期 | 佣金产生后 7 天方可提现（防止退款扣回）|
