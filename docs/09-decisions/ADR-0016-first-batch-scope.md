- 生效版本：v1.0.0
- 决策来源：DEC-016

## 决策
第一批优先整理充值、人工上账、调账、退款/红冲、结算/对账及其权限、状态机、API、数据、测试和部署资料。代理商、业务员、供应商、营销、客服、SSO、完整 Portal 和历史资料暂不迁移正文。

第一批必须打通：`PRD → SPEC → 状态机 → 权限 → API → 数据库 → TEST → OPS`。
