# ADR-0013：24 小时滚动累计限额

- 状态：accepted
- 决策日期：2026-08-29
- 生效版本：v1.0.0
- 决策来源：DEC-013

## 决策
- 按操作人和被入账用户两个维度分别统计，默认均为 ¥50,000。
- 统计人工上账创建、调账调增发起、红冲加钱方向发起。
- 不统计用户自助充值、调账调减、充值审核和兑换码入账。
- 窗口为 `now - 24h ≤ created_at ≤ now`，按滚动窗口计算。
- 申请创建成功时计入；驳回、失败、红冲、取消不回退。
- 超限默认升级至少双人审批，也可配置为直接拒绝。
- 必须记录维度、前值、本笔金额、限额和处置；并发计算原子化。
