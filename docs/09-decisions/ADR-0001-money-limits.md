# ADR-0001：金额上限与审批阈值

- 状态：accepted
- 决策日期：2026-08-29
- 生效版本：v1.0.0
- 决策来源：DEC-001
- 影响范围：充值、人工上账、调账、资金风控、权限、API、测试、部署

## 背景
现有文档对人工上账上限存在 ¥50,000 与 ¥1,000,000 两套口径。

## 决策
- 用户自助充值单笔上限：¥1,000,000。
- 管理员人工上账单笔上限：¥50,000。
- 管理员调账单笔上限：¥50,000。
- 审批阈值独立于单笔上限：≤¥10,000 单人；>¥10,000 且≤¥100,000 双人；>¥100,000 追加 `super_admin` 终审。
- 24 小时累计限额另行定义，不与单笔上限混用。

## 影响与迁移
同步所有资金 PRD/SPEC/API/TEST/OPS；清除“人工上账放开至 ¥1,000,000”的旧口径并保留迁移记录。
