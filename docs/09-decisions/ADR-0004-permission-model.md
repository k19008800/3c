# ADR-0004：权限点鉴权与职责分离

- 状态：accepted
- 决策日期：2026-08-29
- 生效版本：v1.0.0
- 决策来源：DEC-004

## 决策
- 后端统一按权限点鉴权，角色只作权限聚合。
- 前端按权限点控制入口，但不得替代后端校验。
- 无权限统一返回 HTTP 403 `PERMISSION_DENIED`。
- `super_admin` 的 `*` 仅由统一权限守卫解释。
- `finance` 可创建和审核人工上账，但创建人不得审批本人单据。
- `admin` 可执行调账；`super_admin` 具备全权限。
- 强制职责分离：创建人≠审批人、一级审批人≠二级审批人、终审人不得与前级重复。
- 数据范围与操作权限分离；权限变更不追溯已完成资金记录。

## 影响与迁移
逐端点绑定权限点，补齐 403、职责分离和前端显隐测试。
