## 19.1 客户报备管理

### 功能描述

代理商向平台报备意向客户，平台保护代理商的客户归属权益，防止抢单。

### 完成能力 / 展示效果

- **报备客户**：代理商填写客户信息（公司名/联系人/电话）→ 提交报备
- **报备保护期**：报备后 N 天（默认 30 天）内该客户归属该代理
- 保护期内其他代理不可绑定此客户
- 保护期到期后客户未注册 → 报备自动释放
- **报备列表**：已报备 / 保护中 / 已过期 / 已转化
- **转化统计**：报备客户中已注册/已消费的转化率

### 上下游关系

```
代理报备 → 写入 customer_registrations 表
保护期计时 → 定时任务检查到期释放
客户注册 → 自动匹配报备记录 → 绑定代理关系
```

## 19.2 代理商财务中心

### 功能描述

代理商的财务管理页面，集中展示佣金、提现、结算、流水。

### 完成能力 / 展示效果

**财务总览：**
- 账户余额（可提现 / 冻结中 / 待结算）
- 本月收入（佣金）+ 上月收入对比
- 近 6 个月佣金趋势图

**佣金明细：**
- 按用户/时间查看佣金产生记录
- 每个用户的消费贡献排名

**结算记录：**
- 历史结算单列表（时间/周期/金额/状态）
- 结算单详情和下载

**提现记录：**
- 历史提现列表 + 状态追踪

## 19.3 代理端客户消费明细

### 功能描述

代理商查看名下每个客户的详细消费记录。

### 完成能力 / 展示效果

- 选择客户 → 查看该客户的消费明细列表
- 时间范围筛选
- 消费趋势图（近 7 天/30 天）
- 各模型消费分布
- 导出为 CSV

## 19.4 代理端消息通知

### 功能描述

代理商接收平台消息通知（佣金到账、提现结果、客户动态等）。

### 完成能力 / 展示效果

- 通知列表：时间 / 类型 / 内容 / 已读/未读
- 通知类型：佣金到账 / 提现处理结果 / 客户注册提醒 / 客户消费提醒 / 系统公告
- 通知偏好设置：可配置哪些类型接收通知
- 未读消息徽标

## 19.5 代理商等级权益展示

### 功能描述

清晰展示各代理等级的权益对比，激励代理升级。

### 完成能力 / 展示效果

- 当前等级展示
- 等级权益对比表：预备 / 一级 / 高级 / 子代理
- 升级条件：需要达成的指标和进度
- 升级后收益预估：如果升级到高级，预计佣金率提升带来的月收入增加

### [?] 页面帮助

**页面名称**：代理商支撑增强

**适用角色**：代理商、管理员

**功能定位**：代理商端的支撑工具增强：客户报备管理、财务中心、客户消费明细、消息通知、等级权益、移动端适配。

**子模块说明**：
- §19.1 客户报备管理：报备意向客户，30 天保护期内归属该代理，防抢单
- §19.2 代理财务中心：佣金收入、提现记录、结算单查看
- §19.3 客户消费明细：名下客户的消费明细与统计
- §19.4 消息通知：佣金到账/客户预警/报备状态等通知
- §19.5 等级权益：代理等级对应权益说明与升级路径
- §19.6 移动端适配：代理端移动版页面（大屏自动切桌面版）

**注意事项**：
- 客户报备保护期默认 30 天，到期未注册自动释放
- 保护期内客户自行注册（未走邀请链接）会自动匹配绑定到报备代理名下
- 安全告警通知（登录异常/密码修改）强制启用，不可关闭
- 等级每月 1 日重新评估，达标即刻升级
- 移动端适配覆盖手机浏览器，平板/桌面自动切换桌面版

**常见问题**：
Q: 报备的客户保护期多久？
A: 默认 30 天。保护期内该客户归属您，其他代理不可绑定；到期未注册自动释放，可重新报备。

Q: 财务中心没有数据？
A: 新代理商尚无消费客户和佣金记录时展示空状态引导，邀请客户消费后开始产生佣金。

Q: 等级什么时候更新？
A: 每月 1 日重新评估，达标即刻升级，不追溯上月权益。

## 边界条件

| # | 场景 | 触发条件 | 预期行为 |
|---|------|---------|---------|
| AGT-001 | 客户报备保护期内客户自行注册 | 代理报备的客户在 30 天保护期内通过其他渠道自行注册（未使用代理邀请链接） | 系统自动匹配报备记录中的联系方式，将客户绑定到该代理名下，保护期倒计时停止 |
| AGT-002 | 客户报备保护期到期自动释放 | 保护期到期后客户仍未注册平台 | 报备状态自动变更为"已过期"，通知代理"保护期已过，可重新报备或联系客户加速注册" |
| AGT-003 | 代理财务中心账单数据为空 | 新代理商尚无任何消费客户和佣金记录 | 财务中心展示引导式空状态："暂无佣金数据，邀请客户开始赚取佣金"并提供邀请入口 |
| AGT-004 | 代理商等级升级条件未达成但已切换周期 | 月末等级评估时指标未达标，但下月业绩提前达标 | 采用月度评估机制，每月 1 日重新计算等级，达标即刻升级，不追溯上月权益 |
| AGT-005 | 代理端移动版在大屏设备上访问 | 代理商使用平板或桌面端浏览器访问代理端移动版页面 | 检测屏幕宽度后自动切换到桌面版布局，不强制展示移动版 |
| AGT-006 | 通知偏好设置中安全告警被禁用 | 代理商在通知偏好设置中关闭了全部通知类型 | 安全告警（登录异常/密码修改等）强制启用，设置页面的安全告警报开关置灰并标注"安全提醒不可关闭" |
