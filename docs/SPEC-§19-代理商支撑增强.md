## 19.1 客户报备管理

### 功能描述

代理商向平台报备意向客户，平台保护代理商的客户归属权益，防止抢单。

### 完成能力 / 展示效果

- **报备客户**：代理商填写客户信息（公司名/联系人/电话）→ 提交报备
- **报备保护期**：报备后 N 天（默认 30 天）内该客户归属该代理
- 保护期内其他代理不可绑定此客户
- 保护期到期后客户未注册 → 报备自动释放
- **报备列表**：已报备 / 保护中 / 已过期 / 已转化
- **转化统计**：报备客户中已注册/已消费的转化率

### 上下游关系

```
代理报备 → 写入 customer_registrations 表
保护期计时 → 定时任务检查到期释放
客户注册 → 自动匹配报备记录 → 绑定代理关系
```

## 19.2 代理商财务中心

### 功能描述

代理商的财务管理页面，集中展示佣金、提现、结算、流水。

### 完成能力 / 展示效果

**财务总览：**
- 账户余额（可提现 / 冻结中 / 待结算）
- 本月收入（佣金）+ 上月收入对比
- 近 6 个月佣金趋势图

**佣金明细：**
- 按用户/时间查看佣金产生记录
- 每个用户的消费贡献排名

**结算记录：**
- 历史结算单列表（时间/周期/金额/状态）
- 结算单详情和下载

**提现记录：**
- 历史提现列表 + 状态追踪

## 19.3 代理端客户消费明细

### 功能描述

代理商查看名下每个客户的详细消费记录。

### 完成能力 / 展示效果

- 选择客户 → 查看该客户的消费明细列表
- 时间范围筛选
- 消费趋势图（近 7 天/30 天）
- 各模型消费分布
- 导出为 CSV

---

## 19.4 代理端消息通知

### 功能描述

代理商接收平台消息通知（佣金到账、提现结果、客户动态等）。

### 完成能力 / 展示效果

- 通知列表：时间 / 类型 / 内容 / 已读/未读
- 通知类型：佣金到账 / 提现处理结果 / 客户注册提醒 / 客户消费提醒 / 系统公告
- 通知偏好设置：可配置哪些类型接收通知
- 未读消息徽标

---

## 19.5 代理商等级权益展示

### 功能描述

清晰展示各代理等级的权益对比，激励代理升级。

### 完成能力 / 展示效果

- 当前等级展示
- 等级权益对比表：预备 / 一级 / 高级 / 子代理
- 升级条件：需要达成的指标和进度
- 升级后收益预估：如果升级到高级，预计佣金率提升带来的月收入增加

---

## 19.6 代理端移动版适配

### 功能描述

代理端页面适配手机屏幕，支持移动办公。

### 完成能力 / 展示效果

- 响应式设计，手机浏览器访问自动适配
- 移动端核心功能：客户列表 / 佣金看板 / 提现操作 / 消息通知
- 移动端简化版仪表盘
