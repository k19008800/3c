### 功能描述

定义前端组件开发规范，保障 UI 一致性、可复用性和可维护性。

### 完成能力

**15.1 公共组件清单：**

**基础组件：**
- Button（含 loading/disabled 状态、多色系 variant）
- Input（含搜索框/密码框/数字输入）
- Modal / Drawer（弹窗/抽屉）
- Table（含排序/筛选/分页/批量选择）
- Form（含表单校验/布局）
- Select（单选/多选/搜索选择）
- Tag / Badge（标签/徽章）
- Card / StatCard（卡片/统计卡片）
- Loading（加载动画/骨架屏）
- Empty（空状态占位）
- ErrorBoundary（错误边界）
- Pagination（分页）

**业务组件：**
- UserSelect（用户搜索选择器）
- ModelCard（模型卡片）
- KeyDisplay（Key 展示/复制组件）
- BalanceCard（余额卡片）
- LogTable（日志表格）
- StatCard（统计指标卡片）
- TrendChart（趋势图）
- StatusTag（状态标签）

**15.2 组件 Props 规范：**
- 所有组件 TypeScript 类型定义完整
- Props 命名一致：`value` / `onChange` / `disabled` / `loading`
- 组件 Props 类型定义为 `interface` 而非 `type`
- 可选 Props 必须有默认值

**15.3 UI 风格指南：**
- StatsCard 统一 border-2 边框（异常标红/黄）
- 组件配合 ErrorBoundary 使用时包裹 fallback
- 每个组件的 Props 参数定义在独立 interface 文件中
- 工具函数统一导入：`formatNumber` / `formatCurrency` / `formatDate` / `formatRelative`
- Token 计数单位自动转换：K/M/B

**适用角色**：前端开发人员

**子模块说明**：
- §15.1 公共组件清单：基础组件（Button/Input/Modal/Table/Form 等）与业务组件定义
- §15.2 组件规范：命名规范、属性/事件接口、状态定义
- §15.3 视觉规范：色彩/间距/字体/圆角等设计令牌
- §15.4 使用示例：组件用法与代码示例

**注意事项**：
- 新组件需按规范命名并注册到组件库
- 组件变更需保持向后兼容，重大变更需评审
- 设计令牌统一管理，禁止硬编码色值/间距

**常见问题**：
Q: 如何新增一个组件？
A: 按组件库规范创建组件文件、导出注册，并补充文档和示例。

Q: 现有组件不满足需求怎么办？
A: 优先扩展已有组件（保持兼容），确实需要新组件时走组件库评审流程。

## 边界条件

| # | 场景 | 触发条件 | 预期行为 |
|---|------|---------|---------|
| UI-001 | 组件 prop 类型不匹配 | 父组件传入的 prop 类型与组件定义的 interface 不一致（TypeScript 编译通过但运行时异常） | 开发环境控制台输出警告日志，生产环境组件渲染降级为默认值并记录 error boundary 异常 |
| UI-002 | 第三方组件版本升级破坏兼容性 | 基础组件依赖的第三方库（如 antd/echarts）版本升级后接口变更 | 在 package.json 中锁定主版本号，升级前运行全量回归测试，测试失败阻塞发布流水线 |
| UI-003 | 主题覆盖优先级冲突 | 多个组件在不同层级设置了相同 CSS 变量，导致主题样式冲突 | 遵循"就近覆盖"原则：组件级样式 > 页面级样式 > 全局主题变量；覆盖前输出 deprecation 警告 |
| UI-004 | ErrorBoundary 嵌套多层后失效 | 组件树中多个 ErrorBoundary 嵌套，内层抛错时外层无法正确捕获 | ErrorBoundary 仅捕获直属子组件异常，嵌套使用时需在其中手动重新抛出或逐层上报 |
| UI-005 | 骨架屏与真实内容尺寸突变 | 骨架屏渲染尺寸与实际内容加载后的尺寸差异过大 | 骨架屏容器的 min-height/min-width 与实际数据占位一致，避免加载完成后布局跳动 |
| UI-006 | 性能面板频繁重渲染 | TrendChart 组件在实时数据流场景下每秒更新导致卡顿 | 内置 requestAnimationFrame 节流和 React.memo 比较，更新频率不超过 60fps |
