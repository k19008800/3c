## 11.1 客户关系管理（CRM）

### 功能描述

业务员在代理端拥有"我的客户"专属视图，集中管理名下客户。支持标注标签、记录沟通、变更状态。

### 完成能力 / 展示效果

业务员在代理端看到：
- **我的客户列表**：只看归属自己的客户，展示客户名/邮箱/注册时间/最近活跃/消费总额/当前余额/状态
- **客户标签**：支持多标签（企业客户/开发者/高价值/需跟进/流失预警/已签约）
- **联系记录**：每次沟通后记录时间/方式/内容摘要/下次跟进时间
- **客户状态**：意向→试用→活跃→沉默→流失，支持手动变更
- **客户详情页**：整合基本信息 + 消费趋势 + 调用记录 + 工单历史 + 联系记录 + 合同状态

### 上下游关系

```
上游：users 表 → 名下用户
      consumption_logs → 消费趋势
      call_logs → 调用记录
下游：业务员操作（打标签/写联系记录）→ 写入 customer_notes/customer_tags
      状态变更 → 写入 customer_status_log
```

## 11.2 线索管理

### 功能描述

业务员录入和管理潜在客户线索（官网注册/展会/朋友介绍等），管理员可统一分配线索。

### 完成能力 / 展示效果

- **线索录入**：填写姓名/公司/电话/邮箱/微信/需求描述/来源
- **线索状态**：新线索→已联系→意向客户→已成交→无效（需填原因）
- **线索分配**：管理员可将线索分配给指定业务员
- **我的线索列表**（业务员视图）：只看分配给自己的线索
- **全部线索列表**（管理员视图）：可管理和分配所有线索
- **线索转换**：客户注册后自动关联到已有线索

### 上下游关系

```
管理员/业务员录入线索 → leads 表
管理员分配 → 写入 assignedTo
客户注册 → 检测线索 → 自动关联
```

## 11.3 客户跟进提醒

### 功能描述

自动提醒业务员跟进客户，设置下次联系时间，超期预警。

### 完成能力 / 展示效果

- **跟进计划**：设置客户下次联系时间，到期自动提醒
- **超期预警**：超过 N 天未联系，标记为"待跟进"
- **跟进列表**：按"今天要跟/本周要跟/已超期"分组展示
- **提醒方式**：站内通知（可选邮件）

## 11.4 商机与报价管理

### 功能描述

业务员创建商机、生成报价单、提交审批，管理员审批报价。

### 完成能力 / 展示效果

**商机管理：**
- 商机阶段：发现→需求确认→方案→报价→谈判→成交→丢单
- 商机看板：按阶段分组展示（类似 Trello）
- 填写客户需求、预估月消费、期望折扣

**报价单：**
- 选择商机 → 自动生成报价单（含模型清单/折扣价/有效期）
- 超出权限的折扣 → 自动提交上级审批
- 审批通过 → 生成 PDF → 可下载发送给客户

### 上下游关系

```
业务员创建商机 → opportunities 表
  ↓
生成报价单 → quotations 表
  ↓
需要审批 → 提交 admin/财务审批
  ↓
审批通过 → PDF 下载
```

## 11.5 业绩看板

### 功能描述

业务员查看自己的业绩数据（新增客户/消费额/佣金等），同类业务员横向排名。

### 完成能力 / 展示效果

- **本月业绩概览**：新增客户数 / 新增消费额 / 目标完成率 / 商机数 / 成交数
- **业绩趋势**：近 6 个月新增客户数+消费额趋势图
- **客户构成**：按状态分布（活跃/沉默/流失）
- **佣金预估**：本月已产生佣金 + 年化预估
- **排名看板**：同级业务员横向排名
- **目标管理**：管理员设置目标 → 业务员看完成进度

## 11.6 合同管理

### 功能描述

线上合同模板、生成、审批、归档、续签全流程管理。

### 完成能力 / 展示效果

- **合同模板**：预置标准合同模板，含变量占位符
- **合同生成**：选择模板 → 填写客户信息 → 生成合同
- **合同审批**：法务/财务/管理层逐级审批
- **电子签章**：对接第三方服务
- **到期提醒**：到期前 30/15/7 天自动提醒
- **续签**：一键续签，延续上次条款

## 11.7 销售知识库

### 功能描述

业务员可随时查阅产品信息、定价指南、竞品对比、常见问答。

### 完成能力 / 展示效果

- 分类：产品速查 / 定价指南 / 竞品对比 / FAQ / 案例库
- 全文搜索
- 管理员在后台维护内容

---

## 11.8 团队协作与客户交接

### 功能描述

业务员离职/请假时的客户交接，团队管理，线索分配。

### 完成能力 / 展示效果

- **客户转移**：批量将名下客户/线索/商机/合同转移给其他业务员
- **交接记录**：完整审计日志
- **团队视图**（组长可用）：查看组内业务员的业绩
- **线索分配**：组长可分配线索给组员
- **团队业绩汇总**：按团队聚合
