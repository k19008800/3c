## 概述

帮助中心是用户自助解决常见问题的入口。当前 Portal 只有开发者文档，没有面向普通用户的帮助中心。客服 30% 以上的咨询量可以通过自助解决。

**核心价值**：减少 30% 客服咨询量，提升用户自助解决率，降低客服人力成本。

### 2. 文章详情页

文章详情页展示知识库文章内容，支持：
- Markdown 渲染（代码块、表格、图片）
- 目录侧边栏（自动提取 h2/h3 标题）
- 底部反馈 "这篇文章有帮助吗？👍 / 👎"
- 相关文章推荐（同分类其他已发布文章）

### 3. 搜索功能

| 特性 | 说明 |
|------|------|
| 搜索范围 | 标题 + 摘要 + 内容 + 标签 |
| 搜索排序 | 标题匹配 > 标签匹配 > 内容匹配 |
| 空结果 | 显示"没有找到相关结果" + 引导联系客服 |
| 热门搜索词 | 后端记录搜索词频次，运营可查看热门搜索词 |
| 搜索建议 | 输入时显示下拉搜索建议（最多 5 条） |

### 4. 热门文章

自动按浏览量排序展示 Top 10 文章（日更新），管理员可手动置顶特定文章。

### 5. 联系我们入口

帮助中心底部和空搜索结果页提供"联系我们"按钮，点击后跳转到工单创建页（用户登录态）或引导注册/登录。

## API 接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| `GET` | `/api/v1/public/help/categories` | 分类列表（含文章数统计） | 无需登录 |
| `GET` | `/api/v1/public/help/articles?categorySlug=&page=&limit=` | 文章列表 | 无需登录 |
| `GET` | `/api/v1/public/help/articles/:id` | 文章详情 | 无需登录 |
| `GET` | `/api/v1/public/help/search?q=&limit=` | 搜索（含搜索建议） | 无需登录 |
| `GET` | `/api/v1/public/help/articles/hot` | 热门文章 Top 10 | 无需登录 |
| `GET` | `/api/v1/public/help/articles/related/:id` | 相关文章推荐 | 无需登录 |
| `POST` | `/api/v1/public/help/search-logs` | 记录搜索词（前端埋点） | 无需登录 |
| `GET` | `/api/v1/admin/help/search-stats` | 热门搜索词统计 | operator 以上 |

> 帮助中心的文章数据直接复用 `ref-10.2-knowledge-base.md` 中的知识库 API。以上 `/api/v1/public/help/*` 路径是知识库公开 API 的别名，实际指向 `/api/v1/public/knowledge-base/*`。

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 搜索无结果 | 显示空状态引导 + "联系我们"按钮 |
| 文章不存在/已归档 | 返回 404 页面，引导回帮助中心首页 |
| 网络超时 | 显示缓存的热门文章列表（降级展示） |
| SEO | 帮助中心页面使用 SSR 或 SSG 预渲染，路径 `/help/{slug}/{articleId}` |
| 搜索词频率限制 | 每 IP 每分钟最多 30 次搜索请求 |
| 文章浏览量缓存 | Redis 异步写入，每 5 分钟批量回写 DB |

## 验收标准

1. 帮助中心首页按分类展示知识库文章，点击分类进入文章列表
2. 搜索功能正常，搜索结果按相关性排序
3. 文章详情页正确渲染 Markdown 内容，目录导航正常
4. 文章底部"有用/没用"反馈 → 计数更新
5. 热门文章按浏览量排序展示 Top 10
6. 空搜索结果页显示"没有找到相关结果" + "联系我们"按钮
7. 帮助中心页面 SEO 正常（标题/描述/关键词）
8. 移动端适配：分类卡片响应式排列，搜索框正常显示
