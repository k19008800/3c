# 泳道图 6：代理晋升审核流程

> **对应章节**：PRD-README.md §3 代理商体系 — 层级与权益
> **涉及角色**：代理商 / 系统 / 代理管理 / 运营审核
> **状态机**：`preparatory → pending_review → level_1 / level_3 / rejected`

```mermaid
sequenceDiagram
    participant A as 代理商
    participant S as 系统
    participant M as 代理管理岗
    participant O as 运营审核

    Note over A: 预备代理（preparatory）
    Note over A: 基础权限：名下最多 5 个客户，佣金率 10%

    A->>S: ① 在代理端发起升级请求
    S->>S: ② 校验晋升条件

    alt 条件不满足
        S->>A: ③' 返回不满足原因（如：客户数不足 / 月消费未达标）
        Note over A: 不能满足条件，提示还需达到的指标
    else 条件满足
        S->>S: ③ 创建升级请求（status=pending_review）
        S->>A: ④ 返回升级请求已提交，等待审核
        S-->>M: ⑤ [后台] 运营待办队列出现"代理晋升待审"
    end

    M->>S: ⑥ 查看待审列表（代理晋升标签页）
    M->>S: ⑦ 打开代理详情页（历史业绩、名下客户、佣金数据）
    M->>S: ⑧ 提交审核意见

    alt 审核通过
        S->>S: ⑨ 更新代理等级（level_1 / level_3）
        S->>S: ⑩ 更新对应权益（佣金率上限、客户数上限）
        S->>A: ⑪ 通知晋升成功 + 新权益说明
    else 审核拒绝
        S->>S: ⑨' 记录拒绝原因
        S->>S: ⑩' 状态置为 rejected（可重新申请）
        S->>A: ⑪' 通知晋升未通过 + 原因
    end

    Note over O: 审批通过后的运营动作
    O->>S: ⑫ 配置新等级佣金率（阶梯比例）
    O->>S: ⑬ 配置专属权益（活动权限、VIP 通道）
    S->>A: ⑭ 通知权益已激活
```

## 晋升条件配置

| 等级 | 晋升条件 | 佣金率 | 客户数上限 | 额外权益 |
|------|---------|--------|-----------|---------|
| 预备代理 | 注册即自动获得 | 10% | 5 | 基础代金券模板 |
| 一级代理 | 按系统配置（需实名+资质审核通过） | 可配置 | 可配置 | 专属客服、活动权限 |
| 高级代理 | 按系统配置 | 可配置 | 不限 | 专属经理、VIP 通道、定制报价 |

## 关键决策点

| 步骤 | 决策 | 分支 | 说明 |
|------|------|------|------|
| ② | 晋升条件满足？ | 是/否 | 系统自动校验硬性条件 |
| ⑧ | 审核通过？ | 通过/拒绝 | 人工审核（业绩真实性、合规性） |
| ⑩ | 佣金率配置 | 阶梯比例 | 在同一等级内可设置不同比例 |

## 可能的异常场景

1. **代理连续申请被拒** → 3 次拒绝后冻结 30 天
2. **晋升后业绩下滑** → 降级机制（连续 3 月不达标）
3. **代理等级与佣金率不匹配** → 佣金率需在等级范围内配置
4. **晋升审核超时** → 24h 未处理触发告警
