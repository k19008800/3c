# 泳道图 5：自动对账流程

> **对应章节**：PRD-README.md §5.2.4 自动对账
> **涉及角色**：系统（定时任务） / 对账引擎 / 财务
> **运行频率**：每日 02:00（自动）

```mermaid
sequenceDiagram
    participant T as 定时任务（每日02:00）
    participant E as 对账引擎
    participant D as 数据库
    participant F as 财务

    T->>E: ① 触发对账任务

    E->>D: ② 查询昨日所有 call_logs（平台侧）
    E->>D: ③ 查询供应商账单记录（供应商侧）

    Note over E: 两阶段匹配

    rect rgb(240, 248, 255)
        Note over E: 阶段一：精确匹配（request_id）
        E->>E: ④ 按 request_id 逐笔匹配
        E->>E: ⑤ 标记匹配成功/失败
    end

    rect rgb(255, 248, 240)
        Note over E: 阶段二：模糊匹配（无 request_id 时）
        E->>E: ⑥ 按时间 + Token 数 + 模型名 匹配
        E->>E: ⑦ 计算相似度，设置匹配阈值
    end

    E->>D: ⑧ 写入对账结果（reconciliation_results）

    alt 全部匹配（差异 = 0）
        E->>D: ⑨ 更新对账状态 = matched
        E->>F: ⑩ 发送对账完成通知（无差异）
    else 存在差异
        E->>D: ⑨' 更新对账状态 = partial / mismatched
        E->>F: ⑩' 发送对账告警（含差异汇总）

        rect rgb(255, 235, 235)
            Note over F: 对账差异类型
            Note over F: ① 平台有 - 供应商无（N 笔）
            Note over F: ② 供应商有 - 平台无（N 笔）
            Note over F: ③ 金额不一致（N 笔）
            Note over F: ④ 时间偏差（N 笔）
        end

        F->>E: ⑪ 查看差异详情
        F->>E: ⑫ 逐笔核查

        alt 平台有-供应商无
            F->>D: ⑬ 检查是否漏报给供应商
            alt 确认漏报
                F->>D: ⑬-1 补充上报 + 修正记录(operator_id)
            else 非漏报
                F->>D: ⑬-2 标记为平台记录异常，待进一步核查
            end
        else 供应商有-平台无
            F->>F: ⑭ 联系供应商确认是否重复收费
            F->>D: ⑮ 标记为供应商待确认
        else 金额不一致
            F->>E: ⑯ 检查价格配置是否变更
            alt 偏差在容差范围内(<=reconciliation_tolerance_amount)
                F->>D: ⑯-1 标记为已确认差异，记录差异原因
            else 超容差
                F->>D: ⑯-2 人工核正，修复价格或记录
            end
        else 时间偏差(>5min)
            F->>F: ⑰ 检查时钟同步
            F->>D: ⑱ 标记为时间偏差待确认
        end
    end

    F->>D: ⑲ 确认对账完成（对账周期关闭）
    D->>F: ⑳ 生成对账报告（PDF/CSV 导出）
```

## 对账差异分类

| 差异类型 | 含义 | 处理方式 | 优先级 |
|---------|------|---------|--------|
| 平台有 - 供应商无 | 平台记录了消费，供应商账单中无此笔 | 检查是否漏报给供应商 | 🔴 高 |
| 供应商有 - 平台无 | 供应商账单中有记录，但平台无此消费 | 检查是否重复收费 | 🔴 高 |
| 金额不一致 | 双方都有记录但计费金额不同 | 检查价格配置是否变更 | 🟡 中 |
| 时间偏差 | 同一笔记录时间差 > 5 分钟 | 检查时钟同步 | 🟢 低 |
| 已确认差异 | 金额偏差在容差范围内(默认≤¥0.01) | 记录原因后确认不处理 | 🟢 低 |

## 可能的异常场景

1. **对账任务未按时执行** → 延迟告警，重试 3 次
2. **供应商账单格式变更** → 解析失败，标记为"需要人工导入"
3. **大量差异** → 超过 100 笔差异触发紧急告警
4. **对账报告中止** → 部分匹配后中止，标记为"部分完成"
