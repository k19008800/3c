## 9.1 财务总账（科目余额表）

### 功能描述

管理后台财务看板，展示平台完整的科目余额表（收入/支出/资产/负债），财务人员一目了然。

### 完成能力 / 展示效果

管理员（finance 角色）看到：
- **科目余额表**：科目名称 | 期初余额 | 本期发生额（借方/贷方）| 期末余额
- **主要科目**：
  - 收入类：平台收入（用户消费）、代理收入、其他收入
  - 支出类：供应商成本、营销支出、退款支出、手续费
  - 资产类：账户余额总和、平台自有资金
  - 负债类：代理待结算佣金、用户预充值余额
- 每个科目可下钻查看明细流水
- 支持按年月筛选，显示当前结账状态

### 上下游关系

```
上游：
  consumption_logs → 平台收入
  vendor_settlement → 供应商成本
  agent_commission_logs → 代理佣金（负债）
  recharge_logs → 充值资金
  withdraw_logs → 提现支出
下游：
  月度结账 → 锁账 → 生成月度报表
```

## 9.2 月度财务报告

### 功能描述

自动生成月度财务报告，含收入/支出/毛利汇总和趋势分析。

### 完成能力 / 展示效果

- 月度概览：本月收入 / 本月支出 / 本月毛利 / 毛利率
- 收入趋势（近 12 个月）
- 支出构成（供应商成本 / 营销支出 / 退款 / 手续费 饼图）
- 毛利率趋势
- 月度对账汇总：平台记录 vs 各供应商账单，差异项列表
- 导出：PDF 格式下载

## 9.3 财务日报自动推送

### 功能描述

每天早上自动推送前一天的财务日报到指定接收人（邮件/站内通知）。

### 完成能力 / 展示效果

- 日报内容：昨日收入 / 支出 / 充值 / 提现 / 新增用户
- 对比维度：环比前日、同比上周同日
- 异常标注：数据突增/突降时标红
- 推送配置：接收人 / 推送时间 / 推送渠道

## 9.4 授信额度体系

### 功能描述

为高价值企业用户提供信用额度，允许先调用后结算。

### 完成能力 / 展示效果

**管理员配置：**
- 选择用户 → 设置信用额度、账期天数、逾期利率
- 信用额度列表：用户 | 总额度 | 已用额度 | 剩余额度 | 账期 | 状态

**用户端：**
- 控制台余额下方展示信用额度信息
- 调用时优先使用信用额度（余额不足时自动切换）
- 信用额度消耗计入月度账单

**自动处理：**
- 账期到期前 7/3/1 天发送还款提醒
- 逾期未还 → 自动计算逾期费
- 逾期超过 N 天 → 暂停信用额度 → 仅允许余额扣款

### 上下游关系

```
管理员授信 → 写入 credit_limits 表
调用计费 → 余额不足 → 检查信用额度 → 扣信用额度
信用额度消耗 → 生成账单 → 到期提醒
逾期 → 限制调用 → 还款后恢复
```

## 9.5 退款自动化（含佣金扣回）

### 功能描述

处理用户退款请求，自动计算退款金额并逆向扣除代理佣金。

### 完成能力 / 展示效果

**用户发起退款：**
- 选择消费记录 → 申请退款 → 填写原因
- 退款条件：仅可退最近 N 天内的消费（可配置）
- 退款金额 = 消费金额 - 已用部分（按比例计算）

**管理员审核：**
- 待审核列表：用户 | 金额 | 原因 | 提交时间
- 审核详情：查看关联的消费记录
- 操作：[通过] [驳回]

**退款自动处理：**
1. 通过后 → 更新 users.balance（加回退款金额）
2. 逆向计算该笔消费产生的代理佣金
3. 从代理待结算/可提现余额中扣除对应佣金
4. 写入退款日志 + 佣金扣回日志
5. 通知用户 + 通知代理

## 9.6 税票统计看板

### 功能描述

统计平台开票情况，管理发票额度和税务申报所需数据。

### 完成能力 / 展示效果

- 开票统计：本月已开票 / 可开票剩余 / 累计开票总额
- 发票类型分布：普票 / 专票
- 开票趋势（近 12 个月）
- 年度累计：方便税务申报参考
- 导出：汇总数据 CSV

### 上下游关系

```
上游：invoice_requests 表 → 发票数据
下游：税务申报参考
```
