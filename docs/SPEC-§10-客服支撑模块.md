## 10.1 客服工作台

### 功能描述

客服人员在一个页面内集中处理用户咨询，无需在多个页面间切换。聚合展示用户基本信息、余额、充值记录、调用日志、工单历史和操作时间线。

### 完成能力 / 展示效果

客服在管理后台看到"客服工作台"入口，进入后：

- **统一搜索**：输入用户 ID/邮箱/手机号，模糊匹配后直接进入用户信息聚合面板
- **信息聚合面板**（一个页面展示全部）：
  - 用户基本信息（昵称/邮箱/角色/注册时间/实名状态）
  - 余额状态和最近 5 条充值记录
  - 最近 10 条调用日志（快捷查看）
  - 最近工单及回复记录
  - 余额变动流水
- **快捷操作**：无需跳转页面，在工作台内直接调整用户余额、启用/禁用用户
- **操作时间线**：该用户在平台的所有操作按时间线展示

### 上下游关系

```
上游：
  users 表 → 用户基本信息
  recharge_logs → 充值记录
  call_logs → 调用日志
  operation_logs → 操作时间线
下游：
  客服操作（如调整余额）→ 写入 operation_logs
```

## 10.2 知识库系统

### 功能描述

客服可维护内部知识库（常见问题、操作指南、故障处理 SOP），支持分类管理和全文搜索。

### 完成能力 / 展示效果

**管理员/运营：**
- 创建知识库文章：标题 | 分类 | 内容（富文本）| 标签
- 分类管理：自定义分类
- 文章管理：发布/下架/编辑/版本历史

**客服：**
- 在工作台内直接搜索知识库
- 搜索结果展示匹配的文章标题和摘要
- 点击查看文章详情，可复制内容回复给用户

---

## 10.3 用户端帮助中心

### 功能描述

用户在控制台内查看帮助文档/FQA/操作指南，一站式自助解决问题。

### 完成能力 / 展示效果

- 帮助首页：热门问题列表 + 分类导航
- 分类浏览：账户管理 / 充值 / API 调用 / 计费 / 安全 等
- 全文搜索
- 文章阅读页：内容 + 相关文章推荐
- 反馈：文章是否有帮助

---

## 10.4 快捷回复模板

### 功能描述

客服配置常用回复模板，处理咨询时一键选用，提升效率。

### 完成能力 / 展示效果

- 模板列表：名称 | 分类 | 内容（支持变量：{用户名}、{余额} 等）
- 创建/编辑模板
- 客服在回复时选择模板 → 自动填充内容 → 可继续编辑

---

## 10.5 在线客服（WebChat）

### 功能描述

用户在控制台发起即时聊天，客服在管理后台工作台内在线回复。

### 完成能力 / 展示效果

**用户端：**
- 控制台右下角悬浮聊天按钮
- 发起咨询 → 分配客服 → 实时对话
- 消息类型：文字 + 图片

**客服端（管理后台）：**
- 待接入队列：按用户优先级/等待时间排序
- 对话窗口：完整聊天记录 + 快捷回复 + 知识库搜索
- 同时处理多会话

## 10.6 用户操作时间线

### 功能描述

展示用户在平台上的完整操作时间线，帮助客服和分析师回溯问题。

### 完成能力 / 展示效果

时间线按时间倒序展示：
- [时间] 用户注册
- [时间] 用户创建 API Key "xxx"
- [时间] 用户调用 deepseek-chat（消耗 ¥0.50）
- [时间] 用户充值 ¥100
- [时间] 用户提交实名审核
- [时间] 实名审核通过

每条记录可点击查看详情。

- 客服工作台展示的用户数据受权限控制，仅授权客服可见

**常见问题**：
Q: 工作台能看到用户的 API Key 吗？

Q: 用户要求修改信息需要什么权限？
A: 敏感信息（邮箱/手机）修改需二次验证或管理员审批。

## 边界条件

### 模块概述

客服支撑模块包含客服工作台、知识库系统、用户端帮助中心、快捷回复模板、在线客服（WebChat）、用户操作时间线等。个别子模块（ref-10.x）已有边界条件，但 SPEC-§10 层面需要补充跨子模块的协调边界。

### 边界条件清单

| # | 场景 | 触发条件 | 预期行为 | 影响范围 | 优先级 |
|---|------|---------|---------|---------|--------|
| CS-001 | 多个客服同时接待同一用户 | 同一用户被多个客服同时分配或主动接入 | 上一个客服的会话保持活跃，新接入的客服收到"该用户已有进行中会话"提示；可发起会话接管请求，原客服确认后转接 | 用户会话 | P0 |
| CS-002 | 会话转接数据丢失 | 客服将会话转接给其他客服时部分聊天记录未同步 | 转接时自动保存完整会话快照（包括未读消息、附件、上下文）；目标客服收到包含完整历史记录的会话摘要卡片 | 转接会话 | P0 |
| CS-003 | 客服离线未结会话处理 | 客服突然断线或超时离线，仍有未处理完的会话 | 离线超过 5 分钟的未结会话自动进入"待分配"池；离线期间的消息排队等待；客服重新上线后收到离线期间的消息摘要 | 未结会话 | P0 |
| CS-004 | 知识库搜索结果为空 | 用户/客服搜索知识库时关键词无匹配结果 | 支持模糊搜索和同义词扩展；仍无结果时提供"建议新文章"入口；客服端显示"未找到相关内容，将转交人工处理" | 知识库搜索 | P1 |
| CS-005 | 帮助中心页面并发高峰 | 大量用户同时访问帮助中心（如故障公告后） | CDN 缓存热门页面（TTL 3600s）；API 设置独立限流；静态页面不依赖后端服务；升级公告实时显示在帮助中心顶部 | 帮助中心 | P1 |
| CS-006 | 在线客服 WebSocket 断开 | 用户处于客服会话中时 WebSocket 连接意外断开 | 客户端自动重连（指数退避）；重连后同步断连期间的消息；人工客服收到"用户重新连接"的通知；消息队列保证不超过 60 秒丢失 | 当前会话 | P1 |
| CS-007 | 快捷回复模板内容过期 | 快捷回复引用了已失效的产品/价格信息 | 模板引用使用动态占位符（`{{product_name}}`），不硬编码；模板内容由运营团队定期审核；系统自动检测包含失效引用的模板并标记 | 快捷回复 | P1 |
| CS-008 | 操作时间线数据冲突 | 用户操作时间线与实际操作存在不一致（如延迟写入） | 时间线数据来源使用事件源（Event Sourcing），顺序由全局序列号保证；延迟到达的事件按实际发生时间排序，插入到正确位置 | 时间线展示 | P2 |

### 详细边界说明

#### CS-003: 客服离线未结会话

**处理流程**:
1. 检测客服 WebSocket 断开（心跳超时 30s × 3 次）
2. 等待 5 分钟（给客服重新上线的时间）
3. 5 分钟后未恢复 → 将会话重新放入"待分配"队列
4. 会话保留原聊天历史和上下文
5. 重新分配时优先考虑同技能组客服
6. 原客服上线后收到离线通知和未结会话列表

### 异常流程汇总

| 场景 | 恢复策略 | 是否通知 |
|------|---------|---------|
| 多客服同时接待 | 提示已有会话 + 接管机制 | 操作提示 |
| 转接数据丢失 | 完整快照同步 | 无 |
| 客服离线未结会话 | 自动重新分配 | 原客服上线通知 |
| WebSocket 断连 | 自动重连 + 消息持久化 | 无 |
