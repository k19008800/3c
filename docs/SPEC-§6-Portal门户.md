## 6.1 首页 `/`

### 功能描述

平台对外公开的门户首页，展示品牌定位、核心能力、实时数据，引导访客注册或查看文档。

### 完成能力 / 展示效果

访客打开 https://unmisa.com 看到：

**Hero 区域：**
- 标题标语："一站式 AI API 聚合平台"
- 副标题："接入 DeepSeek、OpenAI、Anthropic 等主流模型，统一计费、智能路由、精细运营"
- 3 个 CTA 按钮：[立即注册] [查看文档] [查看模型]

**StatsBanner（实时统计数据）：**
- 已接入模型：138+（实际数据，从数据库实时读取）
- 服务用户：813+（实际数据）
- 累计处理 Token：5.96B+（实际数据，5 分钟缓存）

**功能特性（3 张 Feature Card）：**
- 统一接入：一套 API Key 接入 138+ 模型，兼容 OpenAI 格式
- 智能路由：自动选择最优供应商，故障自动切换
- 精细运营：多级代理体系、实时监控、自动对账、财务双审、安全风控

**数据来源**：`GET /api/v1/public/stats`（5 分钟缓存），请求从 `call_logs` 和 `users` 表聚合

## 6.2 定价页 `/pricing`

### 功能描述

公开展示平台所有模型的定价信息，支持分类筛选和搜索。

### 完成能力 / 展示效果

访客看到定价表格：
- 分类标签：全部模型 / 对话 / 嵌入 / 图像 / 音频
- 表格列：模型名称 | 供应商 | 输入价格 (¥/1K tokens) | 输出价格 (¥/1K tokens) | 上下文长度
- 数据源自 `GET /api/v1/public/pricing`（5 分钟缓存），仅展示 active 状态的模型

底部 FAQ 区：
- Q: 如何计费？→ 按 Token 计费，输入和输出分别计价
- Q: 有套餐吗？→ 按量计费，用多少付多少。可联系销售获取企业定制方案
- Q: 有免费额度吗？→ 注册即送 ¥5 试用额度

## 6.3 模型目录 `/models`

### 功能描述

模型列表页，访客可浏览所有可用模型，点击查看详情，引导注册使用。

### 完成能力 / 展示效果

- 搜索框：按模型名称搜索
- 分类筛选：全部 / 对话 / 嵌入 / 图像 / 音频 / 重排序 / 视频
- 模型卡片网格（每行 3-4 个）：模型名 / 供应商 / 类型标签 / 价格 / 上下文长度
- 点击弹窗详情：模型名 | 供应商 | 类型 | 上下文长度 | 输入价格 | 输出价格 | 支持特性 | 描述
- [立即使用] 按钮 → 跳转到注册/登录

## 上下游关系概览（Portal 整体）

```
外部访客 → portal.unmisa.com（公开）
   ├─ 首页 → 展示实时统计数据（5 分钟缓存）
   ├─ 定价页 → 读取 vendor_models 公开价格
   ├─ 模型目录 → 读取 models 表 active 状态
   └─ 开发者文档 → 静态 Markdown 内容

注册引导 → 跳转到 /console（用户端）
使用流程：访客浏览 → 注册 → 创建 Key → 调用 API
```

### 边界条件

| 场景 | 行为 |
|------|------|
| 统计数据无法获取 | 展示上一次缓存值，标注"数据来自缓存" |
| 模型全部下线 | 定价页展示"暂无可用模型"提示 |
| 注册按钮 | 已登录用户跳转到控制台，未登录跳转到注册页 |

### 错误码参考页

开发者文档中包含完整的错误码参考页面，以表格形式展示所有 API 错误码：
- 错误码 | HTTP 状态 | 含义 | 处理建议 | 代码示例
- 涵盖：invalid_api_key(401) / key_disabled(403) / insufficient_balance(402) / rate_limit_exceeded(429) / model_not_found(404) 等
- 限流错误额外展示 retry_after 使用方式
- 每个错误码附带代码示例（cURL/Python）说明如何正确处理
