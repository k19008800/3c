## 25.1 供应商结算对账

### 功能描述

供应商自助页面增加结算对账功能，展示结算周期、应收金额、已付金额、待对账明细。支持导出对账单。

### 完成能力 / 展示效果

**供应商端结算页面：**

```
结算中心
  ┌────────────────────────────────────────────┐
  │  当前结算周期: 2026-07-01 ~ 2026-07-31      │
  │                                              │
  │  基础服务费:          ¥12,500.00             │
  │  质量扣减:            -¥250.00               │
  │  应结算总额:          ¥12,250.00             │
  │  结算状态:            ⏳ 待对账              │
  │                                              │
  │  [查看明细] [导出对账单 CSV]                  │
  └────────────────────────────────────────────┘

  历史结算
  周期            总额          状态          结算日期
  2026-06         ¥11,200.00   ✅ 已结算     2026-07-10
  2026-05         ¥10,800.00   ✅ 已结算     2026-06-08
```

### 数据来源

现有供应商费用的聚合结算 — 基于 `vendor_costs` 表按结算周期聚合：

```
├── 基础服务费: 周期内累计调用费用总和
├── 质量扣减: 根据 SLA 达标率折算（可用性 < 99.9% 扣减比例）
└── 应结算总额: 基础服务费 - 质量扣减
```

### API 接口

```
GET  /api/v1/vendor/settlement/current        — 当前结算信息
GET  /api/v1/vendor/settlement/history        — 历史结算列表
GET  /api/v1/vendor/settlement/:id/detail     — 结算明细
GET  /api/v1/vendor/settlement/:id/export     — 导出对账单 CSV
```

### 验收标准

#### □ 流程图一致性校验 — 与对应流程图对比验证流程分支、异常处理、决策节点完全一致

1. 供应商端展示当前结算周期的应结算金额和明细
2. 供应商可下载对账单 CSV
3. 历史结算记录可按月份查看

## 25.2 供应商公告/通知

### 功能描述

平台通过公告系统向供应商推送通知（API 变更、结算通知、新模型上线要求、系统维护等），供应商在自助后台查看。

### 通知类型

| 类型 | 触发场景 | 紧急程度 |
|------|---------|---------|
| 结算通知 | 结算单生成/结算完成 | 高 |
| API 变更 | 平台 API 版本升级/参数调整 | 高 |
| 新模型上线 | 要求供应商接入新模型 | 中 |
| 系统维护 | 平台系统维护通知 | 中 |
| 政策变更 | 结算政策/分成比例变更 | 高 |

### API 接口

```
GET  /api/v1/vendor/notifications          — 通知列表
GET  /api/v1/vendor/notifications/:id      — 通知详情
PUT  /api/v1/vendor/notifications/:id/read — 标记已读

// 管理后台发送
POST /api/v1/admin/vendor/notifications    — 向供应商群发通知
```

### 验收标准

1. 供应商后台显示平台推送的通知列表
2. 通知内容和紧急程度正确展示
3. 供应商可标记通知为已读

## 25.3 供应商性能排行榜

### 功能描述

内部运营工具，展示各供应商的健康评分、响应速度、错误率、成本效率等多维度对比。用于运营决策和供应商管理。

### 展示内容（管理后台）

```
供应商性能排行 — 2026-07 月
  排名  供应商   健康评分  平均延迟  错误率   调用量    综合得分
  🥇   DeepSeek  98.5      380ms     0.12%   8.2M      95.2
  🥈   阿里云    97.2      210ms     0.25%   5.1M      93.8
  🥉   GLM       95.8      890ms     0.80%   2.3M      88.5
  4     OpenAI   92.1      1200ms    1.50%   1.8M      82.3
```

### 数据来源

```
├── 健康评分: 供应商健康检查通过率（按小时采样，近 7 天平均）
├── 平均延迟: 供应商 API 响应时间（近 7 天平均）
├── 错误率: 调用失败率（近 7 天）
├── 调用量: 近 7 天总调用次数
└── 综合得分: 加权计算（健康 30%+延迟 25%+错误率 25%+成本 20%）
```

### 验收标准

1. 管理后台展示供应商性能排行榜
2. 各项指标和综合得分正确计算
3. 可查看不同时间范围的排名

## 25.4 供应商自助结算

### 功能描述

供应商可主动发起结算申请，平台审核后完成打款。区别于被动等待周期结算。

### 流程

```
供应商发起结算申请 → POST /api/v1/vendor/settlement/request
  └── 校验条件:
       ├── 当前周期内未申请过
       └── 待结算金额 ≥ ¥500（最小结算额）
  └── 状态: pending

管理员审核 → 管理后台结算审核页面
  └── 查看结算明细 → 确认或驳回
  └── 确认 → 状态变为 confirmed → 触发打款流程
  └── 驳回 → 填写驳回原因 → 供应商可修改后重新申请
```

### API 接口

```
// 供应商端
POST /api/v1/vendor/settlement/request      — 发起结算申请
GET  /api/v1/vendor/settlement/requests     — 结算申请记录

// 管理后台
GET  /api/v1/admin/vendor/settlement/requests       — 待审核结算申请
POST /api/v1/admin/vendor/settlement/:id/approve    — 审核通过
POST /api/v1/admin/vendor/settlement/:id/reject     — 驳回（需填写原因）
```

### 验收标准

1. 供应商发起结算申请 → 管理后台看到待审核
2. 管理员审核通过 → 结算流程开始
3. 管理员驳回 → 供应商看到驳回原因
4. 不满足条件（金额不足/已申请过）→ 提示友好错误
