## 概述

客服每天处理大量用户咨询，需要在用户信息、余额、调用记录、工单历史等多个页面之间来回切换。当前没有统一工作台，客服必须开 4-5 个浏览器标签页才能完整了解一个用户的情况。

**核心价值**：一个页面解决客服 80% 的日常操作需求，信息聚合免切换。

### 3. 快捷操作

| 操作 | 说明 | 权限要求 |
|------|------|---------|
| 调整余额 | 弹窗填写金额+备注+是否发送通知给用户 | 客服专员（限额：单次 ≤ ¥500）|
| 禁用/启用用户 | 确认后执行，记录操作日志 | 客服组长以上 |
| 重置密码 | 生成临时密码，记录操作日志 | 客服专员 |
| 查看 API Key | 跳转到用户 API Key 管理页（系统直接查看） | 客服专员 |
| 新建工单 | 以用户名义创建工单，自动填充用户信息 | 客服专员 |
| 添加联系记录 | 弹窗填写沟通内容/方式/下次跟进时间 | 客服专员 |

**权限分层**：
- **客服专员**：搜索用户、查看信息、调整余额（限额）、查看API Key、新建工单、添加联系记录
- **客服组长**：以上全部 + 禁用/启用用户、无限制调整余额、批量操作
- **客服主管**：以上全部 + 配置快捷回复、管理客服账号

### 4. 多用户切换

客服可同时处理多个用户咨询，不丢失上下文：

- 每个用户信息面板以**标签页**形式存在（类似浏览器 Tab）
- 最多同时打开 5 个用户标签页
- 标签页标题显示用户名称/ID + 未读状态（如有新工单回复）
- 关闭标签页时自动保存操作记录

```
┌─────────┬─────────┬──────────────────────────────────┐
│ 张三    │ 李四    │ ＋ 新搜索                         │
│ ✕       │ ✕       │                                  │
│ (查看中) │ (有新回  │                                  │
│          │ 复！)   │                                  │
└─────────┴─────────┴──────────────────────────────────┘
```

### 5. 会话历史

聚合面板底部显示客服与用户的最近交互记录：

- 最近的工单回复（从工单系统拉取）
- 最近的客服备注（从联系记录拉取）
- 按时间线混排展示

### 6. 用户时间线入口

聚合面板底部提供"查看完整时间线"按钮，跳转到 §10.5 用户时间线页面（全量操作日志）。当前面板仅显示工单和调用记录等高频信息。

## API 接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| `GET` | `/api/v1/admin/support/user-search?q=&limit=` | 搜索用户（ID/邮箱/手机号模糊匹配） | 客服专员以上 |
| `GET` | `/api/v1/admin/support/user-dashboard/:userId` | 用户信息聚合面板数据 | 客服专员以上 |
| `GET` | `/api/v1/admin/support/user-dashboard/:userId/call-logs?limit=` | 最近调用记录 | 客服专员以上 |
| `GET` | `/api/v1/admin/support/user-dashboard/:userId/tickets?limit=` | 最近工单 | 客服专员以上 |
| `GET` | `/api/v1/admin/support/user-dashboard/:userId/balance-log?limit=` | 最近余额变动 | 客服专员以上 |
| `POST` | `/api/v1/admin/support/user-balance/adjust` | 调整余额（含限额校验） | 客服专员以上 |
| `POST` | `/api/v1/admin/support/user-status/toggle` | 禁用/启用用户 | 客服组长以上 |
| `POST` | `/api/v1/admin/support/user-password/reset` | 重置密码 | 客服专员以上 |

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 搜索无结果 | 显示"未找到匹配用户"，建议检查输入是否正确 |
| 搜索命中大量结果（>50） | 分页 + "精确匹配"和"模糊匹配"分组展示，精确匹配置顶 |
| 用户已注销/删除 | 信息面板提示"该用户已注销（yyyy-mm-dd）"，只读不可操作 |
| 余额调整超过限额 | 客服专员超限额 → 弹窗提示"单次调整限额 ¥500，如需调整请联系组长" |
| 同时打开标签页超过 5 个 | 提示"最多同时打开 5 个用户"（同时引导关闭已处理用户） |
| 网络超时加载 | 已加载的部分信息保留展示，未加载区域显示加载失败 + 重试按钮 |
| 搜索防抖 | 输入停止 300ms 后触发搜索请求 |
| API 响应缓存 | 用户信息聚合面板数据缓存 30 秒（Redis），避免高频同用户查询 |

## 验收标准

1. 搜索用户支持 ID/邮箱/手机号模糊匹配，精确匹配结果置顶
2. 信息聚合面板一个页面展示用户基本信息、余额与消费、最近调用记录、工单历史
3. 快捷操作弹窗正常（调整余额、禁用/启用、重置密码）
4. 余额调整有权限控制和限额校验
5. 多用户标签页支持同时打开 5 个用户，切换不丢失上下文
6. 禁用用户时二次确认 + 操作日志记录
7. 聚合面板数据缓存 30 秒后刷新

**页面名称**：客服工作台
**核心操作**：通过搜索快速定位用户 → 查看用户全貌信息 → 执行快捷操作（调整余额/禁用用户/新建工单）
