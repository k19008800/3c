## 12.1 操作审计控制台

### 功能描述

系统管理员查看所有管理员操作的可审计日志，支持多维度筛选、差异对比、异常模式识别和一键回滚。

### 完成能力 / 展示效果

管理员在管理后台进入"审计日志"：

- **多维度筛选**：时间范围 / 操作人 / 操作类型 / 资源类型 / 影响范围
- **审计日志列表**：时间 | 操作人 | 操作类型 | 目标类型/ID | IP | 状态
- **操作详情**：点击查看 before/after JSON diff，变更字段高亮显示
- **异常模式识别**：系统自动标记可疑操作（如凌晨批量改配置、敏感操作）→ 异常操作列表
- **操作回滚**：对配置类变更，一键回滚到变更前状态（仅超级管理员权限）
- **导出**：CSV/JSON 两种格式

### 上下游关系

```
上游：所有操作 → 写入 operation_logs 表
下游：审计控制台 → 管理员查询
      异常检测 → 标记可疑操作
      回滚 → 恢复配置变更
```

## 12.2 数据库管理面板

### 功能描述

可视化查看数据库运行状态，包括表大小、索引状态、慢查询、连接数等。

### 完成能力 / 展示效果

- **表空间概览**：按大小排序展示所有表（行数/磁盘占用/增长趋势）
- **索引管理**：索引列表（大小/使用率/冗余索引检测）
- **慢查询**：慢查询日志列表 + 执行计划查看
- **连接监控**：当前连接数/活跃连接/等待连接
- **表分区状态**：分区表的各分区数据量

## 12.3 缓存管理控制台

### 功能描述

管理员查看和管理 Redis 缓存状态，支持清空指定缓存键。

### 完成能力 / 展示效果

- **缓存概览**：Redis 内存使用率 / Key 数量 / 命中率
- **缓存列表**：按前缀分组的 Key 列表（如 billing:*, routing:*）
- **清空缓存**：按前缀清空 / 按 Key 精确清空 / 全清
- **缓存命中率趋势图**

---

## 12.4 任务调度中心

### 功能描述

查看和管理平台所有定时任务和后台作业。

### 完成能力 / 展示效果

- **任务列表**：任务名 | 调度表达式 | 上次执行时间 | 上次结果 | 状态（运行中/暂停/失败）
- **任务详情**：执行历史（每次的执行时间/耗时/结果/错误日志）
- **手动触发**：手动立即执行一次任务
- **暂停/恢复**：控制任务调度
- **任务类型**：
  - 财务类：每日对账、月度账单生成、结算
  - 运营类：用户分层计算、召回扫描、日报推送
  - 系统类：缓存预热、数据清理、健康检查
  - 安全类：安全事件检测、风险评分更新

## 12.5 在线日志查看器

### 功能描述

管理员在管理后台直接查看服务器应用日志，无需 SSH 登录。

### 完成能力 / 展示效果

- **日志查看**：实时 tail 模式 / 历史搜索
- **日志筛选**：按级别（ERROR/WARN/INFO/DEBUG）、时间范围、模块
- **日志分析**：错误聚合（相同错误分组计数）、趋势图
- **日志下载**：导出筛选后的日志片段

## 12.6 健康检查大屏

### 功能描述

平台所有服务（API/Redis/PostgreSQL/供应商 API）的健康状态一目了然。

### 完成能力 / 展示效果

- **服务列表**：服务名 | 状态（正常/异常/离线）| 响应时间 | 上次检查时间
- **健康评分**：综合计算平台整体健康分（0-100）
- **历史趋势**：各服务健康状态变化时间线
- **故障关联分析**：当多个服务同时异常时，标注可能关联

## 12.7 变更计划与沙箱预览

### 功能描述

计划性变更（配置修改/功能发布）先在沙箱环境预览影响范围。变更从沙箱验证通过后经审批推送到生产环境，形成完整的变更闭环。

### 完成能力 / 展示效果

- **变更计划**：创建计划 → 填写变更内容/影响范围/回滚方案/时间窗口
- **沙箱预览**：在沙箱环境执行变更 → 验证结果 → 确认后才推生产
- **变更审批**：重要变更需审批 → 审批通过执行
- **变更记录**：历史变更列表 → 可追溯每次变更

### 沙箱→生产推送审批闭环

变更从沙箱验证通过到推送到生产的完整流程：

```
┌─ 创建变更计划 ──────────────────────────────┐
│  变更标题: [调整 deepseek-chat 加价率]        │
│  变更类型: 配置变更 / 功能发布 / 版本升级       │
│  影响范围: 影响所有 deepseek 模型调用计费       │
│  回滚方案: 回滚到 v40 配置版本                  │
│  时间窗口: 2026-07-30 23:00-01:00            │
│  创建人: admin@3cloud.ai                     │
│  状态: ⏳ 草稿                                │
└──────────────────────────────────────────────┘

│  3. 自动运行验证脚本:                         │

         ↓
┌─ 提交审批 ──────────────────────────────────┐
```

### 变更类型与审批策略

| 变更类型 | 沙箱验证要求 | 审批人数 | 通知范围 | 回滚策略 |
|---------|------------|---------|---------|--------|
| 配置参数修改 | 自动执行 | 1 人 | 变更发起人 | 一键回滚上一个版本 |
| 模型价格变更 | 自动验证 + 手动确认 | 2 人 | 运营 + 财务 | 自动回滚 + 价格检查 |
| 路由策略调整 | 运行测试用例 | 2 人 | 运维 + 运营 | 自动回滚 + 熔断恢复 |
| 功能发布（前端） | 自动 E2E 测试 | 1 人 | 相关方 | 前端版本回滚 |
| 功能发布（后端） | 自动 E2E 测试 + 性能测试 | 2 人 | 所有管理员 | 数据库迁移回滚 |
| 数据库结构变更 | 需 DBA 审核 | super_admin 仅 | 所有管理员 | 迁移回滚脚本执行 |

| 模块 | 优先级 | 预估工作量 | 核心价值 |
|------|--------|-----------|---------|
| 操作审计控制台 | P0 | 后端 3d + 前端 4d | 操作追责+异常模式识别，安全合规 |

| 任务调度中心 | P1 | 后端 4d + 前端 4d | 定时任务统一管理，失败及时发现 |
| 在线日志查看器 | P1 | 后端 3d + 前端 3d | 无需 SSH 即可查看日志，安全便捷 |
| 缓存管理控制台 | P1 | 后端 2d + 前端 3d | 缓存可视化，按需清理 |
| 数据库管理面板 | P2 | 后端 4d + 前端 4d | 数据库状态可视化，辅助性能调优 |
| 变更计划与沙箱预览 | P2 | 后端 4d + 前端 4d | 降低变更风险，支持计划编排 |
| 系统升级与版本管理 | P2 | 后端 3d + 前端 3d | 版本可追溯，一键回滚，灰度发布 |

**合计**：后端 26 人天 + 前端 29 人天 = 约 7 周

> 权限说明：系统管理员模块操作影响系统稳定性，所有 API 均需超级管理员权限。部分高危操作（如回滚/部署/执行 SQL）需额外二次确认弹窗。

### 系统工具权限矩阵（与 §30 权限系统集成）

每个系统工具子模块需要绑定到 §30 的权限资源上，以便在自定义角色中精细化控制访问。

| 模块 | 资源标识 | 可操作角色 | 高危操作 | 二次确认要求 |
|------|---------|-----------|---------|------------|
| 操作审计控制台 | `admin_tools:audit` | super_admin / admin / auditor | 操作回滚 | 需二次确认弹窗 + 输入登录密码 |
| 数据库管理面板 | `admin_tools:database` | super_admin 仅可查看，不可执行 SQL | 慢查询查看、表空间查看 | 查看慢查询需二次确认 |
| 缓存管理控制台 | `admin_tools:cache` | super_admin / admin | 清空指定缓存、全清缓存 | 清空缓存需二次确认；全清需双人审批 |
| 任务调度中心 | `admin_tools:scheduler` | super_admin / admin | 手动触发任务、暂停/恢复任务 | 暂停关键任务需二次确认 |
| 在线日志查看器 | `admin_tools:logs` | super_admin / admin / ops | 无（只读） | 无 |
| 健康检查大屏 | `admin_tools:health` | super_admin / admin / ops | 无（只读） | 无 |
| 变更计划与沙箱预览 | `admin_tools:changes` | super_admin / admin | 沙箱→生产推送 | 需审批流程（见 §12.7 变更管理）|  
| 系统升级与版本管理 | `admin_tools:upgrade` | super_admin 仅 | 版本部署、一键回滚 | 回滚需二次确认 + 输入登录密码；版本部署需双人审批 |
