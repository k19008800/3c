## 一、性能指标

> 基于 2026-07 性能优化成果（PERF-OPT-FINAL-REPORT.md）：32 个瓶颈全修复，后端 12 处、前端 11 处、数据库 21 索引 + 4 外键

### 1.1 API 响应时间

| 接口分类 | 目标 P95 | 目标 P99 | 当前状态 | 关键优化措施 |
|---------|---------|---------|---------|-------------|
| 简单查询（单表/主键） | < 100ms | < 200ms | ✅ 已达标 | 索引覆盖、LRU 缓存 |
| 列表分页（含筛选） | < 200ms | < 500ms | ✅ 已达标 | 复合索引、LIMIT 下推 |
| 复杂聚合（统计/趋势） | < 500ms | < 2s | ✅ 已达标 | 物化视图、Redis 缓存 5min |
| 模糊搜索（ILIKE） | < 100ms | < 200ms | ✅ 已达标 | trigram 索引（pg_trgm） |
| 日志查询（分区表） | < 1s | < 3s | ✅ 已达标 | 按月分区、分区裁剪 |
| 批量操作（万级） | < 3s | < 5s | ✅ 已达标 | 批量写入优化、N+1 修复 |

### 1.3 数据库

| 指标 | 目标值 | 当前状态 |
|------|-------|---------|

## 二、可用性（SLA）

### 2.1 可用性指标

| 指标 | 目标值 | 当前实现 | 备注 |
|------|-------|---------|------|
| 系统可用性 | **99.9%**（年宕机 < 8.76h） | PM2 cluster + Nginx | 单节点，无 HA |
| 计划内停机 | 每月 < 30 分钟 | PM2 零宕机重载 | 部署期间无停机 |
| 故障恢复时间（RTO） | < 15 分钟 | 服务重启 / 脚本恢复 | 手动恢复 |
| 数据恢复点（RPO） | < 5 分钟 | PostgreSQL WAL 归档 | 归档模式 |
| 熔断恢复 | < 5 分钟 | 自动健康检查 + 恢复 | 供应商故障自动恢复 |

### 2.2 架构保障

| 层级 | 保障措施 | 说明 |
|------|---------|------|
| 应用层 | PM2 cluster mode（多实例） | 请求分发，实例间无状态 |
| 反向代理 | Nginx 反向代理 | 静态资源缓存、负载均衡 |
| 数据库 | PostgreSQL 17 | 索引、分区、WAL 归档 |
| 缓存 | Redis 6（Memurai 开发） | 热点数据缓存、限流/锁 |
| 容错 | 熔断器 | 供应商故障自动隔离 |
| 限流 | 四级限流 | 全局/用户/Key/模型 |

### 2.3 备份策略

| 备份项 | 频率 | 保留周期 | 恢复方式 |
|-------|------|---------|---------|
| 数据库全量 | 每日 04:00 | 7 天 | pg_dump + psql 恢复 |
| WAL 归档 | 连续 | 按需 | PITR 恢复 |
| 应用配置 | 版本控制 | 全部历史 | git checkout |
| 前端构建 | 部署时保留 | 最近 3 个版本 | Nginx 目录切换 |

### 2.4 灾备方案

| 场景 | 响应动作 | 预计恢复时间 | 自动/手动 |
|------|---------|-------------|---------|
| 应用进程崩溃 | PM2 自动重启 | < 30s | 自动 |
| 数据库连接失败 | 重试 + 告警 | < 5min | 手动 |
| 服务器宕机 | 备用服务器（123.60.55.62）| < 30min | 手动 |
| 数据损坏 | PITR 恢复 | < 1h | 手动 |
| 安全事件 | 隔离 + 重建 | 视情况 | 手动 |
