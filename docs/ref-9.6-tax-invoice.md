## 概述

财务人员每月需要统计开票数据——本月开了多少发票、多少金额、多少是专票多少是普票、哪些客户还没开票。当前只能手工从发票系统导出数据，效率低且容易出错。

**核心价值**：开票数据一目了然，辅助财务做税务申报和发票管理。

### 6. API 接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| `GET` | `/api/v1/admin/invoice-stats/summary?year=&month=` | 税票总览 | 财务 |
| `GET` | `/api/v1/admin/invoice-stats/trend?months=12` | 开票趋势 | 财务 |
| `GET` | `/api/v1/admin/invoice-stats/detail?startDate=&endDate=&type=&page=&limit=` | 开票明细 | 财务 |
| `GET` | `/api/v1/admin/invoice-stats/uninvoiced` | 未开票预估 | 财务 |
| `GET` | `/api/v1/admin/invoice-stats/uninvoiced/customers` | 未开票客户列表 | 财务 |
| `GET` | `/api/v1/admin/invoice-stats/export?format=csv|xlsx|pdf&filters=` | 导出 | 财务 |

### 7. 边界条件

| 场景 | 处理方式 |
|------|---------|
| 当月无开票数据 | 显示"本月暂无开票记录"，不显示空图表 |
| 未开票统计为 0 | 显示"所有消费均已开票" |
| 汇率（多币种场景） | 统一按开票时汇率换算为人民币统计 |
| 开票数据跨年 | 按自然年/月切换，支持跨年对比 |
