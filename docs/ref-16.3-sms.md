## 概述

系统需要短信服务用于验证码发送、安全提醒、通知推送。当前使用阿里云短信/腾讯云短信/Twilio（海外），已经对接了发送逻辑，但缺少统一的管理界面和配置功能。

**核心价值**：短信发送可配置、可监控、可追溯，降级策略明确。

---

## 功能模块

### 1. 发送场景

| 场景 | 触发条件 | 发送对象 | 优先级 |
|------|---------|---------|--------|
| 登录验证码 | 用户选择短信登录 | 用户手机号 | 高 |
| 安全提醒 | 异地登录检测 | 用户手机号 | 高 |
| 充值通知 | 充值到账 | 用户手机号 | 中 |
| 异常告警 | 系统异常触发告警规则 | 管理员手机号 | 高 |
| 跟进提醒 | 业务员跟进提醒（可选） | 业务员手机号 | 低 |

### 2. 模板管理

短信模板在服务商后台配置，系统内维护模板 ID 映射：

```typescript
// sms_templates — 短信模板映射
export const smsTemplates = pgTable("sms_templates", {
  id: serial("id").primaryKey(),
  scene: varchar("scene", { length: 30 }).notNull().unique(), // login_code | security_alert | recharge | alert
  provider: varchar("provider", { length: 20 }).notNull(), // aliyun | tencent | twilio
  templateId: varchar("template_id", { length: 50 }).notNull(), // 服务商模板 ID
  params: jsonb("params"), // 参数映射 [{name, type}]
  enabled: boolean("enabled").notNull().default(true),
  updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
});
```

### 3. 发送限流

| 维度 | 限制 |
|------|------|
| 每手机号每分钟 | 最多 1 条 |
| 每手机号每天 | 最多 10 条 |
| 每 IP 每天 | 最多 50 条（验证码场景） |
| 全局每分钟 | 最多 100 条 |

### 5. 降级策略

| 场景 | 降级方案 |
|------|---------|
| 服务商不可用 | 自动切换备用服务商 |
| 所有服务商不可用 | 降级为邮件通知 |
| 限流触发 | 提示"短信发送频繁，请稍后再试" |
| 发送失败 | 自动重试 3 次（间隔 30s），仍失败转邮件 |

### 6. API 接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| `GET` | `/api/v1/admin/integrations/sms/config` | 短信配置 | 超管 |
| `PATCH` | `/api/v1/admin/integrations/sms/config` | 更新短信配置 | 超管 |
| `POST` | `/api/v1/admin/integrations/sms/test` | 发送测试短信 | 超管 |
| `GET` | `/api/v1/admin/integrations/sms/logs?page=&limit=&status=&phone=` | 发送记录 | 超管 |
| `GET` | `/api/v1/admin/integrations/sms/stats` | 发送统计（日/周/月） | 超管 |

### 7. 边界条件

| 场景 | 处理方式 |
|------|---------|
| 用户未绑定手机号 | 跳过短信发送，记录日志 |
| 手机号格式错误 | 校验后拒绝发送，返回错误提示 |
| 服务商配置缺失 | 页面显示"短信服务未配置" |
| 验证码有效期 | 5 分钟过期，超时需重新获取 |

### 8. 关联模块

| 模块 | 关联方式 |
|------|---------|
| 用户登录 | 短信验证码登录 |
| 安全事件 | 异地登录触发短信提醒 |
| 通知系统 | 充值/告警通知推送到短信 |
