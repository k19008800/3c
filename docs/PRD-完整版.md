## 一、产品定位

**3cloud（3C）** 是一个 AI API 聚合平台，对接多家模型供应商（DeepSeek、OpenAI、Anthropic、OspreyAI、LLMRouter、天翼云等），为下游开发者、企业和代理商提供统一的 API 接入、Token 计费、智能路由和全链路运营管理能力。

### 核心价值

| 维度 | 说明 |
|------|------|
| **统一接入** | 一套 API Key 接入多家供应商的数百种模型 |
| **成本优化** | 智能路由自动选择最优性价比的供应商/模型 |
| **精细运营** | 多级代理体系、实时监控、自动对账、财务结算 |
| **安全合规** | 实名认证、IP 白名单、双因素认证、风控引擎 |

## 二、用户体系

### 2.1 角色权限模型（RBAC）

| 角色等级 | 角色 | 说明 | 管理范围 |
|---------|------|------|---------|
| 🏆 | `super_admin` | 超级管理员 | 全部系统配置、财务、安全、用户管理 |
| 🥇 | `admin` | 管理员 | 分配的管理范围 |
| 🥇 | `finance` | 财务岗 | 充值审核、提现审核、对账、发票 |

| 🥇 | `security` | 安全岗 | 安全事件、实名审核、风控规则 |
| 🥇 | `agent_mgr` | 代理商管理 | 代理商审核、佣金配置 |
| 🥈 | `agent` | 代理商 | 管理名下用户/子代理、查看财务 |
| 🥉 | `user` | 普通用户 | 使用 API、管理 Key、查看用量 |
