> **目的**：为 3cloud 项目重写提供完整到"直接开发不踩坑"级别的规格文档
> **补充对象**：第一批 P0 核心模块

> 1. 每个模块补全**状态机完整定义**（所有状态 + 所有转换 + 每个转换的副作用）

> 3. 每个模块补全**并发/竞态保护策略**
> 4. 每个模块补全**与关联模块的数据一致性契约**
