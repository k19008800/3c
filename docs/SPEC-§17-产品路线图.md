# 功能说明书：§17 产品迭代路线图

> **对应文档**：[`PRD-产品路线图.md`](PRD-产品路线图.md)

---

### 功能描述

产品迭代的版本规划和优先级排期，指导开发团队按节奏推进。

### 版本规划

| 版本 | 时间 | 范围 | 核心目标 |
|------|------|------|---------|
| v1.0 | 当前 | 已有功能 + §8-§12 新增 | 完成所有 P0 功能，达到上线标准 |
| v1.1 | v1.0 + 1 个月 | P1 功能 | 完善客服/财务/业务员支撑 |
| v1.2 | v1.1 + 1 个月 | P2 功能 | 全功能版本 |
| v2.0 | 待定 | 架构升级 | 微服务拆分、多活部署 |

### P0 优先（当前版本 v1.0）

| 优先级 | 模块 | 预估工作量 | 依赖 |
|--------|------|-----------|------|
| P0-1 | §8 运营增长 | 后端 8d + 前端 8d | 用户系统已就绪 |
| P0-2 | §9 财务模块 | 后端 12d + 前端 10d | 计费系统已就绪 |
| P0-3 | §10.1 客服工作台 | 后端 3d + 前端 4d | 工单系统已就绪 |
| P0-4 | §10.2 知识库 | 后端 4d + 前端 4d | 无依赖 |
| P0-5 | §10.3 帮助中心 | 前端 3d | 依赖知识库 |
| P0-6 | §11.1 CRM | 后端 4d + 前端 5d | 用户系统已就绪 |
| P0-7 | §11.2 线索管理 | 后端 3d + 前端 3d | 无依赖 |
| P0-8 | §12.1 审计控制台 | 后端 3d + 前端 4d | audit_logs 已存在 |
| P0-9 | §12.6 健康检查 | 后端 3d + 前端 4d | 无依赖 |

### P1 优先（v1.1）
包括：快捷回复模板 / 在线客服 / 用户操作时间线 / 跟进提醒 / 商机报价 / 业绩看板 / 合同管理 / 缓存管理 / 任务调度 / 日志查看 / 第三方集成

### P2 优先（v1.2）
包括：销售知识库 / 团队协作 / 数据库面板 / 变更计划 / 版本管理 / 组件库规范

### 技术债清理计划
- v1.0：Drizzle ORM exists 子查询兼容 / 日志表分区迁移
- v1.1：剩余大组件拆分 / 统一错误码规范 / 完善单元测试覆盖率 > 80%
- v2.0：微服务架构评估
