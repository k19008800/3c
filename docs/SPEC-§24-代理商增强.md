## 24.0 总览

### 功能描述

在现有代理商体系（三级审核、佣金规则、提现双审）基础上，补充增长引擎、客户管理和多级扩展能力。

### 子模块清单

| 编号 | 模块 | 优先级 | 核心价值 |
|------|------|--------|---------|
| 24.1 | 代理商邀请裂变 | P1 | 代理可生成专属邀请链接，被邀请人注册后自动绑定为下级客户 |
| 24.2 | 代理商素材库 | P2 | 提供宣传海报/文案/PPT 等素材，代理可直接下载使用 |

## 24.1 代理商邀请裂变

### 功能描述

代理商可生成专属邀请链接/二维码，客户点击链接注册后自动绑定为该代理的下级客户。代理端可追踪每个邀请链接的转化效果（曝光/点击/注册/消费）。

### 完成能力 / 展示效果

**代理端邀请页：**

```

  │  邀请链接:                                   │
  │  https://unmisa.com/register?agent=AG001    │ [复制]
  │                                              │
  │  邀请二维码:                                  │
  │  [QR Code]                                   │ [下载]
  │                                              │
  │  已邀请: 25 人 | 已注册: 18 人 | 已消费: 8 人 │
  └────────────────────────────────────────────┘

  邀请效果统计（近 30 天）
  日期      曝光  点击  注册  消费总额

  07-27     98     12    2    ¥156.00

  合计      2,340  320  18   ¥4,560.00
```

### 数据表扩展

```typescript

```

### API 接口

```
GET  /api/v1/agent/referral/links               — 邀请链接列表

GET  /api/v1/agent/referral/stats               — 邀请效果统计
GET  /api/v1/agent/referral/clients             — 邀请注册的客户列表及消费

// 注册接口扩展（已存在）

```

### 验收标准

#### □ 流程图一致性校验 — 与对应流程图对比验证流程分支、异常处理、决策节点完全一致

1. 代理生成专属邀请链接 → 发送给客户 → 客户注册后自动绑定为该代理的下级
2. 代理看到邀请统计（曝光/点击/注册/消费）
3. 代理可生成多个邀请链接用于不同渠道
4. 注册时携带 agent 参数 → 用户 profile 标记 referred_by_agent

## 24.4 代理商客户预警

### 功能描述

代理名下客户出现异常时（余额不足 / 调用量骤降 / 即将到期），平台主动通知代理进行客户关怀，减少客户流失。

### 预警类型

| 预警类型 | 触发条件 | 通知内容 |
|---------|---------|---------|
| 余额不足 | 客户余额 < ¥10 | "您的客户张三余额仅剩 ¥3.50，建议提醒充值" |
| 调用骤降 | 日调用量较 7 日均值下降 > 80% | "您的客户李四 API 调用量骤降 85%，是否联系了解情况？" |
| 余额即将耗尽 | 按当前速度 3 天内余额耗尽 | "客户王五余额预计 2 天后耗尽，建议提前联系续费" |
| 客户流失 | 连续 14 天无调用 | "客户钱七已 14 天未使用，请确认是否流失" |

### API 接口

```
GET /api/v1/agent/alerts/clients     — 客户预警列表
PUT /api/v1/agent/alerts/:id/dismiss — 标记已处理
```

### 验收标准

1. 代理端显示名下客户的预警列表
2. 预警触发时代理收到站内通知
3. 代理可标记预警为"已处理"

## 24.5 代理商多级佣金

### 功能描述

当前仅支持一级佣金。扩展为支持二级：代理商发展下级代理，下级代理的佣金按比例抽成给上级。

### 佣金抽成规则

```
├── 一级代理: 直接发展客户的消费 → 按佣金规则结算
├── 二级代理: 上级代理 50% 的佣金中抽成 20%
│   └── 例: 二级代理佣金 ¥100 → 上级代理额外获得 ¥20
└── 运营后台配置: 上级抽成比例（默认 20%）
```

### 验收标准

1. 上级代理可查看名下所有下级代理的业绩汇总
2. 下级代理结算佣金时，上级自动获得对应抽成
3. 运营后台可配置抽成比例

## 24.6 代理商自定义定价

### 功能描述

代理可为其名下客户设置不同的价格倍率，类似"渠道定价"。代理需要更高的利润空间时，可在平台基础价格上上浮一定比例。

### 规则

```
├── 平台基础价格: ¥0.50 / 1K tokens（deepseek-chat）
├── 代理可设置倍率: 1.0x ~ 2.0x
│   └── 1.2x → 客户实际价格: ¥0.60 / 1K tokens
├── 代理利润: 客户支付价格 - 平台基础价格 = 代理利润空间
└── 运营后台可设置代理倍率上限（默认 2.0x）
```

### 验收标准

1. 代理可为名下客户单独设置价格倍率
2. 不同客户可设置不同倍率
3. 客户在计费时按代理设置的价格倍率计算
4. 倍率上限由运营后台控制

## 边界条件

| # | 场景 | 触发条件 | 预期行为 |
|---|------|---------|---------|
| ENH-001 | 邀请链接在未注册状态被恶意刷量 | 恶意用户批量点击代理邀请链接但不注册，导致曝光/点击数据虚高 | 系统检测单 IP 单位时间内点击超过阈值（如 100 次/小时）时，该 IP 的点击不纳入统计，标记为异常流量 |
| ENH-002 | 代理排行榜计算时并行结算 | 排行榜统计截止时刻，仍有代理佣金正在计算中 | 以定时快照为准（每日凌晨 3:00），榜单冻结后不因后续佣金变动而更新，代理自行确认是否参与排名 |
| ENH-003 | 客户预警频繁触发导致通知风暴 | 某一客户因调用骤降而频繁触发预警（如每分钟一条） | 同类型预警合并发送，同一客户同类型预警间隔不低于 4 小时 |
| ENH-004 | 多级佣金链中出现循环代理关系 | A 代理发展 B 为下级代理，B 又发展 A 为下级代理（系统或人工错误） | 系统在建立代理关系时循环检测，发现循环时拒绝操作并提示"代理关系存在循环依赖，请检查" |
| ENH-005 | 代理自定义定价导致客户支付价格异常 | 代理将价格倍率设置为 0.0x 或超过上限 2.0x | 前端校验限制：倍率输入框范围 1.0x ~ 2.0x（步长 0.1x），超出范围无法保存 |
| ENH-006 | 素材库文件大小超限 | 管理员上传的素材文件超过存储限制（默认 50MB） | 后端校验拒绝上传，前端提示"文件大小不能超过 50MB"，展示当前文件大小 |
| AGT-013 | 代理商激活时效过期 | 注册代理商超过 30 天未完成激活 | 系统自动回收注册资格，释放关联的手机号和邮箱 |
| AGT-014 | 代理商信用额度超限 | 代理商当前欠款超过设定的信用额度 | 冻结创建新订单权限，发送通知要求还款后方可恢复 |
| AGT-015 | 代理商批量操作中断 | 批量导入/修改代理商信息过程中发生错误 | 回滚已执行的部分操作，记录错误行号并提供修正后的重试 |
| AGT-016 | 多级代理佣金冲突 | 多级代理佣金计算时产生环路 | 系统检测佣金环路并报告给管理员，阻止计算扩散 |
| AGT-017 | 代理商区域冲突 | 同一区域被多个代理商同时申请 | 优先分配给先申请者，后续申请自动标记为"区域冲突"并通知双方协商 |
| AGT-018 | 代理商标识变更 | 代理商改名、变更法人后需更新系统记录 | 保持原有内部 ID 不变，仅更新显示名称并记录变更历史 |
