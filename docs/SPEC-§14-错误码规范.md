# 功能说明书：§14 错误码规范

> **对应文档**：[`PRD-错误码规范.md`](PRD-错误码规范.md)

---

### 功能描述

定义平台 API 错误码规范，统一错误响应格式，覆盖认证、鉴权、限流、模型、计费等全场景。开发者文档中提供完整错误码参考页。

### 完成能力

**统一错误响应格式：**
```json
{
  "error": {
    "code": "error_code",
    "message": "中文描述",
    "details": {}  // 可选，额外上下文
  }
}
```

**完整错误码列表：**

| 错误码 | HTTP 状态码 | 含义 | 处理建议 |
|--------|----------|------|---------|
| `invalid_api_key` | 401 | API Key 不存在 | 检查请求头 Authorization |
| `key_disabled` | 403 | API Key 已被禁用 | 在控制台启用该 Key |
| `key_expired` | 403 | API Key 已过期 | 在控制台续期或创建新 Key |
| `insufficient_balance` | 402 | 余额不足 | 充值后重试 |
| `rate_limit_exceeded` | 429 | 请求频率超限 | 降低请求频率，等待 retry_after |
| `model_not_found` | 404 | 模型不存在 | 检查请求中的 model 参数 |
| `model_unavailable` | 503 | 模型暂时不可用 | 稍后重试或切换到其他模型 |
| `content_filtered` | 400 | 请求命中内容过滤 | 修改请求内容 |
| `ip_not_allowed` | 403 | IP 不在白名单 | 检查 IP 白名单设置 |
| `region_blocked` | 403 | 地区被封锁 | 联系管理员解除封锁 |
| `internal_error` | 500 | 服务器内部错误 | 稍后重试，持续请联系客服 |

**全局错误码规范（§14.1）：**
- 所有 API 响应使用统一 JSON 格式
- 错误码字符串化，不暴露内部技术细节
- 每个错误附带中文可读消息
- 限流错误额外返回 `retry_after`（重试等待秒数）
- 错误码定义在统一枚举中，前后端共享

**前端异常处理策略（§14.3）：**
- 全局 HTTP 拦截器统一捕获错误码
- 401/403 → 跳转登录页或提示无权限
- 402 → 弹窗引导用户充值
- 429 → 显示友好的"请求过于频繁"提示
- 500 → 统一弹窗"服务异常，请稍后重试"
