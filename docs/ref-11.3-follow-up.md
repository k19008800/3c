## 概述

业务员客户多了以后容易忘记跟进——客户 30 天没登录了、上次联系是两个月前。当前没有跟进提醒机制，客户流失往往从"忘了跟"开始。

**核心价值**：自动提醒业务员及时跟进客户，降低客户沉默流失率。

## 功能模块

### 1. 跟进提醒列表

```
跟进提醒

  ┌──────────────────────────────────────────────────────┐
  │ 🔴 今天待跟进（5）                                     │
  ├────────┬──────────┬──────────┬────────┬───────────┤
  │ 客户名  │ 上次联系  │ 提醒方式  │ 剩余时间 │ 操作      │
  ├────────┼──────────┼──────────┼────────┼───────────┤
  │ 张三    │ 07-20    │ 电话     │ 2h     │ [跟进]   │
  │ 李四    │ 07-15    │ 微信     │ 已超期 │ [跟进]   │
  └────────┴──────────┴──────────┴────────┴───────────┘

  ┌──────────────────────────────────────────────────────┐
  │ 🟡 本周待跟进（12）                                    │
  │ 🟢 已超期（3） — 超过 30 天未联系                     │
  └──────────────────────────────────────────────────────┘
```

| 分组 | 定义 |
|------|------|
| 今日待跟进 | nextFollowUp 为今天或已超期 ≤ 3 天 |
| 本周待跟进 | nextFollowUp 在本周内（未来） |
| 已超期 | 超过 N 天（默认 14 天）未有任何联系记录 |

### 2. 跟进规则配置

管理员可配置跟进规则：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 沉默提醒天数 | 14 天 | 客户超过 N 天无联系 → 标记"待跟进" |
| 超期升级天数 | 30 天 | 客户超过 N 天无联系 → 标记"已超期" + 上报组长 |
| 通知渠道 | 站内通知 | 支持站内通知 / 邮件 / 短信 |
| 提醒时间 | 09:00 | 每日固定时间推送跟进汇总 |

### 3. 跟进后操作

业务员点击"跟进"后弹出记录表单：

```
跟进记录

  客户: 张三
  跟进方式: [电话 ▼]
  沟通内容: [____________________]
  下次跟进: [2026-08-06 ▼] [不设置]
  更改客户状态: [不更改 ▼]

  [提交] [取消]
```

提交后：
- 创建一条联系记录（customer_notes）
- 更新 nextFollowUp
- 跟进提醒从列表中移除

### 4. 批量跟进

选中多个客户 → 批量标记"已跟进"（较少使用，用于统一回访活动后批量记录）。

## API 接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| `GET` | `/api/v1/agent/follow-ups` | 我的跟进列表（今日/本周/超期分组） | 业务员 |
| `GET` | `/api/v1/agent/follow-ups/today` | 今日待跟进客户 | 业务员 |
| `PATCH` | `/api/v1/agent/follow-ups/:userId/next` | 设置下次跟进时间 | 业务员 |
| `POST` | `/api/v1/agent/follow-ups/:userId/done` | 标记已跟进（含联系记录） | 业务员 |
| `POST` | `/api/v1/agent/follow-ups/batch/done` | 批量标记已跟进 | 业务员 |
| `GET` | `/api/v1/admin/follow-up-rules` | 跟进规则配置 | 管理员 |
| `PATCH` | `/api/v1/admin/follow-up-rules` | 更新跟进规则 | 管理员 |

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 今日待跟进列表为空 | 显示"今天没有待跟进客户 🎉" |
| 业务员不设置下次跟进 | 不强制要求，留下次跟进时间为空 |
| 跟进规则变更后存量客户 | 按新规则重新计算，不追溯历史 |
| 批量标记已跟进 | 不记录联系内容，仅记录操作日志 |
