### 功能描述

规范平台数据迁移流程，包括从零初始化、旧版数据迁移、第三方导入、表结构变更后校验。

### 完成能力

**迁移场景覆盖：**

| 场景 | 说明 |
|------|------|
| 零基础初始化 | 全新系统从空数据库开始，seed 脚本可重复执行 |
| 旧版数据迁移 | 从旧版或其他平台迁入用户/订单/消费记录 |
| 第三方导入 | 从其他聚合平台批量导入用户和 Key |
| 表结构变更 | migration 执行后的数据迁移和校验 |

**目录结构规范：**
- `seeds/` — 种子数据（角色权限 / 管理员 / 分类 / 邮件模板 / 系统配置）
- `transforms/` — 数据转换脚本（用户 / 订单 / Key）
- `validate/` — 校验脚本（数据完整性 / 引用完整性 / 数据一致性）

**要求：**
- 所有脚本可重复执行（IF NOT EXISTS / 幂等设计）
- 迁移前自动备份受影响表
- 迁移完成后自动校验数据完整性
- 大表分批迁移（每批 1000 条），支持断点续传

**迁移脚本规范：**
- 脚本统一放在 `api/src/migrations/` 目录，分三类：
  - `seeds/` — 种子数据（角色权限/管理员/分类/模板/配置）
  - `transforms/` — 数据转换脚本（用户/订单/Key）
  - `validate/` — 校验脚本
- 每次迁移必须有对应的回滚脚本
- 执行后自动记录迁移版本号到 `migration_versions` 表

**数据校验规则：**
- 完整性校验：源表行数 = 目标表行数
- 引用完整性校验：外键关联无断裂
- 数据一致性校验：关键字段（余额/金额）サンプリング对比
- 校验结果报告：通过/失败项目列表

**API 接口：**

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | /api/v1/admin/migrations/run | 执行迁移 | 超级管理员 |
| POST | /api/v1/admin/migrations/rollback | 回滚迁移 | 超级管理员 |
| GET | /api/v1/admin/migrations/status | 迁移状态列表 | 管理员 |
| GET | /api/v1/admin/migrations/validate | 执行数据校验 | 超级管理员 |

## 边界条件

| # | 场景 | 触发条件 | 预期行为 |
|---|------|---------|---------|
| MIG-001 | 迁移执行中断后恢复 | 分批迁移执行到第 N 批时进程崩溃/网络中断 | 重启迁移时自动从断点处继续，不重复执行已提交批次，状态标记为"部分完成" |
| MIG-002 | 数据一致性校验失败 | 迁移完成后行数校验或抽样校验发现源/目标不一致 | 迁移任务标记为"校验失败"，自动回滚已迁移数据，生成差异报告供人工核查 |
| MIG-003 | 迁移时间窗口超时 | 大表迁移实际耗时超过预设的维护窗口时间 | 暂停当前迁移进程，保留已完成批次数据，等待下一个维护窗口继续执行 |
| MIG-004 | 增量迁移与存量迁移冲突 | 在执行存量数据迁移期间，业务系统持续产生增量数据导致数据版本不一致 | 采用快照+增量双阶段策略：先锁定快照时间点迁移存量，再追平增量日志 |
| MIG-005 | 回滚脚本执行失败 | 迁移需回滚时，回滚脚本因数据依赖或版本兼容性问题执行失败 | 标记回滚为"手动介入"状态，输出当前数据库差异报告，提供人工修复指引 |
| MIG-006 | 迁移版本号冲突 | 在分布式环境中两个节点同时执行了不同的迁移版本 | 以最先提交的迁移版本为准，后续冲突版本打回并提示需重新编号 |
| MIG-007 | 迁移中断恢复 | 数据迁移过程中网络中断或服务重启 | 迁移任务自动暂停，重启后从中断点继续执行，不重复迁移已完成数据 |
| MIG-008 | 数据校验失败-修复选项 | 迁移后数据校验发现源与目标记录不一致 | 标记不一致记录并生成差异报告，提供自动修复或手动修复选项 |
| MIG-009 | 增量迁移冲突-源目标冲突 | 增量迁移期间源端和目标端同时对同一条记录进行修改 | 以目标端版本为基准，冲突记录标记为"手动修复"并通知管理员介入 |
| MIG-010 | 迁移目标空间不足 | 目标数据库存储空间不足以容纳待迁移数据 | 迁移任务暂停并发出告警，要求扩容后继续 |
| MIG-011 | 大数据量迁移性能 | 单次迁移记录数超过 100 万条 | 自动启用批量分片（每批 10000 条），显示进度百分比并预估剩余时间 |
| MIG-012 | 迁移版本不兼容 | 源数据库版本与目标数据库版本差异超过一个大版本 | 拒绝执行迁移，提示升级或降级源/目标版本 |
