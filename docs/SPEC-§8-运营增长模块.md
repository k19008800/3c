## 8.1 代理兑换码配额与绑定

### 功能描述

代理商可领取兑换码配额分发给名下客户，用于拉新和激励。通过兑换码绑定客户关系，确保代理佣金归属清晰。

### 完成能力 / 展示效果

**管理员端：**
- 创建兑换码批次：数量 × 面额 × 有效期 → 分配给指定代理
- 查看代理配额使用情况：已领取/已分发/已兑换/已过期

**代理端：**
- 代理商在代理端看到自己的兑换码配额池
- 可批量生成链接或单个兑换码，分发给名下用户
- 每个兑换码由用户兑换后，该客户自动绑定到该代理名下
- 代理可查看兑换码使用统计（兑换数/带来的消费额）

### 上下游关系

```
管理员创建批次 → 分配给代理
代理领取配额 → 分发给用户
用户兑换 → 获得额度 → 绑定代理关系
代理收到佣金（用户消费产生）
```

## 8.2 充值活动自动赠送

### 功能描述

管理员可配置充值满赠活动（如充 ¥1000 送 ¥100），用户充值后系统自动赠送。

### 完成能力 / 展示效果

**管理员配置：**
- 创建活动：活动名称 / 时间范围 / 规则（充 X 送 Y / 送比例 / 送固定金额）/ 适用用户
- 效果统计：参与人数、赠送总额、带来的额外充值

**用户端：**
- 充值页面展示当前活动信息："活动：充 ¥1000 送 ¥100！"
- 充值成功后到账金额 = 充值金额 + 赠送金额
- 赠送金额记录在余额变动日志中（标记为"活动赠送"）

### 上下游关系

```
管理员配置活动 → 写入 campaigns 表
用户充值 → 充值引擎检查是否有进行中活动 → 匹配则赠送
赠送 → 更新 users.balance + 写入 consumption_logs（赠送条目）
```

## 8.3 用户分组推送

### 功能描述

按用户分层/标签分组，精准推送活动通知和运营内容。

### 完成能力 / 展示效果

- 选择推送分组：种子用户 / 活跃用户 / 普通用户 / 休眠用户 / 流失用户
- 支持组合筛选：如"月消费 > ¥100 且 近 7 天未登录"
- 推送形式：站内通知 + 邮件
- 推送统计：发送数 / 到达数 / 点击率

## 8.4 自动化流失召回

### 功能描述

系统自动识别流失用户并执行召回流程（邮件 + 优惠券），管理员配置召回策略。

### 完成能力 / 展示效果

**自动化流程：**
1. 每日检测：users 表中超过 30 天无登录的用户
2. 自动触发第一轮召回：发送"我们想你了"邮件 + 赠送 ¥5 优惠券
3. 如 7 天后仍未登录 → 第二轮召回：更大力度的优惠
4. 管理员在后台查看召回效果：发送数 / 打开率 / 召回率 / 召回用户后的消费额

**管理员配置：**
- 召回触发条件（流失天数阈值）
- 各轮次召回的内容模板和优惠力度
- 召回频率和最大召回次数

### 上下游关系

```
定时任务（每日）→ 扫描流失用户
  ↓
召回引擎 → 匹配召回策略 → 推送通知 + 发送优惠
  ↓
用户登录/消费 → 召回成功 → 标记为已召回
  ↓
反馈统计 → 召回率/消费额分析
```

## 8.5 推荐码营销系统

### 功能描述

老用户生成推荐码邀请新用户，推荐成功后双方获得奖励。支持推荐绑定关系。

### 完成能力 / 展示效果

- 老用户在控制台生成推荐链接/推荐码
- 新用户注册时填写推荐码，绑定推荐关系
- 推荐成功条件：被推荐用户首次消费 ≥ ¥X
- 奖励方式：双方各获得 ¥Y 额度 / 老用户获得 Z% 佣金
- 推荐排行：展示推荐人数 Top 榜

### 上下游关系

```
老用户生成推荐码 → 分享给朋友
朋友注册填写推荐码 → 绑定推荐关系
朋友消费 → 触发奖励 → 双方获得额度
```

### [?] 页面帮助

**页面名称**：运营增长模块

**适用角色**：管理员（运营/市场）

**功能定位**：提供运营增长工具：兑换码拉新、营销活动配置、优惠策略管理、用户增长与转化数据分析。

**子模块说明**：
- §8.1 代理兑换码配额与绑定：代理商领取兑换码配额分发给客户，拉新并绑定客户关系
- §8.2 营销活动：充值返现/消费折扣/邀请奖励等活动的配置与发放
- §8.3 优惠策略：优惠券、折扣码等优惠策略管理
- §8.4 增长分析：用户增长、转化率、活动效果分析

**注意事项**：
- 兑换码有数量配额和有效期限制，过期未使用自动回收
- 营销活动涉及资金发放，配置需运营审批
- 活动成本计入 ROI 分析（见 §33.5）

**常见问题**：
Q: 兑换码发出去没用会怎样？
A: 兑换码有有效期，过期未使用自动回收，不影响配额。

Q: 活动能中途停止吗？
A: 可以，但已发放的奖励仍需兑现，停止后不再产生新奖励。
