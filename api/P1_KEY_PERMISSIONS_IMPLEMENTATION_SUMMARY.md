## 权限验证流程

1. **API Key认证**
   ```
   客户端请求 → 提取API Key → 计算Hash → 查询数据库
   → 验证状态/过期时间 → 验证基本权限 → 返回认证结果
   ```

2. **权限验证层次**
   ```
   IP白名单验证 → IP黑名单验证 → 时间段验证
   → 模型权限验证 → 端点权限验证 → 额度验证
   ```

3. **实时额度统计**
   ```
   请求成功 → 计算费用 → 更新每日/每月额度
   → 检查额度限制 → 记录使用统计
   ```
