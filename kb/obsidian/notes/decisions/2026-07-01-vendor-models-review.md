# 供应商模型映射模块设计评审决策

**日期**：2026-07-01

**背景**：3cloud 项目「供应商模型映射（vendor_models）」功能模块设计稿完成，进行了全面的布局/功能/交互/无障碍评审。

## 评审结论

### 做得好的
- 表格信息密度合理，12 列覆盖核心字段
- 健康状态可视化（百分比 + 红黄绿色 + 宕机图标）
- 价格分区（成本价红色/售价绿色）
- Modal 表单分组逻辑清晰

### P0 缺失功能（需优先补齐）
1. **行内启用/禁用切换** — 当前需进编辑弹窗才能改状态，加 Switch 组件
2. **连通性测试按钮** — 发简单 API 请求到上游，返回延迟 + 是否成功

### P1 建议功能
- 供应商/模型筛选下拉（后端 API 已支持 vendorId/modelId 参数）
- 批量导出 CSV（不含 API Key）
- 顶部汇总卡片（启用/宕机/禁用计数）

### P2 后续迭代
- 供应商名/模型名可点击跳转
- 价格毛利预览（实时计算）
- 模板化快速创建（"从已有映射复制"）

## 技术要点
- 后端 API 的 vendorId/modelId 筛选在当前实现中通过条件拼接
- 注意 `vendorId` 和 `modelId` 参数正确传递给 API
