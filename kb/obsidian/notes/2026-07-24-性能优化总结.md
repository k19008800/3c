## 🔧 文件上传功能增强

### 1. 详细日志记录
- **记录字段**：操作员ID、IP地址、文件名、耗时、错误原因
- **日志格式**：
  ```javascript
  [Upload] { operatorId: 2, ip: "192.168.1.1", filename: "logo.png", success: true } 耗时: 123ms
  ```

### 2. 定期清理孤儿文件
- **Cron 任务**：每周日 03:00 自动执行
- **功能**：扫描 `uploads/site/` → 对比 `system_configs` 表 → 清理未引用且超过7天的文件
- **手动执行**：
  ```bash
  npx tsx scripts/clean-orphan-uploads.ts --dry-run    # 预览
  npx tsx scripts/clean-orphan-uploads.ts             # 实际删除
  ```

### 3. 磁盘空间监控
- **监控频率**：每小时检查 uploads 目录磁盘空间
- **告警阈值**：剩余 < 500MB 时控制台告警
- **日志示例**：
  ```
  [DiskMonitor] ⚠️ 磁盘空间不足: 剩余 234.5MB (最小 500MB)
  ```
