# 3cloud V2 迭代升级方案

> 借鉴枭毅 (OspreyAI / New API) 平台，对标差距 + 差异化创新

---

## 总体策略

| 原则 | 说明 |
|------|------|
| 借鉴不照搬 | 保留 3cloud 代理体系和双审机制 |
| 增量不重写 | 在现有 schema 上扩展 |
| 三端对齐 | 每功能覆盖 用户端/代理端/管理后台 |

## 版本规划

```
V2.0（本期，2-3 周）     V2.1（下期）        V2.2（远期）
├── 兑换码系统           ├── Rerank 接入      ├── Audio TTS/STT
├── 管理 API Key 分离    ├── Image 生成       ├── Video 生成
├── 用户额度预算         ├── OAuth 扩展       ├── Moderation
├── 通道熔断器增强       ├── 2FA 认证         ├── 开放平台 OAuth
├── 供应商自助管理 API   ├── 异步任务系统     └── 企业 SSO
├── 用量聚合统计 API     └── 模型类型扩展
└── 站内信/通知增强
```

## V2.0 核心功能

### 1. 兑换码系统 ⭐⭐
- 用户端：输入兑换 → 即时到账
- 代理端：批量生成 → 导出分发 → 统计
- 管理后台：规则配置 → 全量查看 → 数据看板

详见：[[3cloud-redemption-code-design|兑换码管理系统设计]]

### 2. 管理 API Key 分离 ⭐⭐
- 支持运维脚本/CI 程序化调用管理接口
- 细粒度权限（按模块：read/write/delete）

### 3. 用户额度预算 ⭐⭐
- 代理商控制下游客户消耗上限
- 企业客户按部门/项目设置预算
- Key 级别额度

### 4. 通道熔断器增强 ⭐
- 三级熔断：软降级 → 半开 → 永久
- 自动 Failover 到同模型其他供应商

### 5. 供应商自助管理 API ⭐
- 供应商自助上下架模型、更新价格、轮换 Key

### 6. 用量聚合统计 API ⭐
- 按模型/供应商/时间维度聚合
- 物化视图 + Redis 缓存优化

### 7. 站内信/通知增强 ⭐
- 站内信收件箱 + 邮件通知
- 完整通知矩阵（实名/安全/额度/提现等）

## 开发计划

| 阶段 | 功能 | 开发量 |
|------|------|--------|
| 第1周 | 兑换码系统 + 用量聚合统计 API | 5天 |
| 第2周 | 管理 API Key + 额度预算 + 通知增强 | 5天 |
| 第3周 | 熔断器增强 + 供应商自助 API + 联调 | 5天 |

**总计：约 15 个工作日（3 周）**

## 差异化优势

完成 V2.0 后，3cloud 核心差异优势：**代理体系 + 财务双审 + 安全合规**
