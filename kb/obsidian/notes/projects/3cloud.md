# 3cloud 项目文档

> 最后更新: 2026-07-21
> 项目定位: AI Token 聚合平台

---

## 项目概述

3Cloud (3C) 是一款 AI API 聚合平台，对接 DeepSeek、OpenAI、Anthropic、枭毅(OspreyAI)、LLMRouter 等多家模型供应商，为下游开发者/企业/代理商提供统一的 API 接入、Token 计费、智能路由和全链路运营管理能力。

### 发现的问题

#### 1. `/admin/stats` — 聚合统计
- **错误**: `Route GET:/api/v1/admin/stats/by-user?limit=50&days=30 not found`
- **影响**: "按用户" 标签页数据无法加载，显示空白
- **根因**: 后端未注册 `/api/v1/admin/stats/by-user` 路由
- **优先级**: 中

#### 2. `/admin/finance/code-cost` — 兑换码成本看板
- **错误**: `Route GET:/api/v1/admin/finance/code-cost?period=2026-07&page=1&pageSize=20 not found`
- **影响**: 整个页面无数据
- **根因**: 后端未实现 code-cost 财务统计端点
- **优先级**: 低（新功能）

#### 3. `/admin/finance/settlement` — 代理结算对账
- **错误**: `请求失败 (404)`
- **影响**: 页面无数据
- **根因**: 后端 settlement 路由缺失或 404
- **优先级**: 低（新功能）

## 2026-07-18 — Key 资源池管理 + 后端服务拆分

### Key 资源池功能上线

在供应商管理模块中新增 **Key 资源池** 功能：

- **资源池 CRUD**：创建/编辑/删除资源池，支持策略：轮询(round_robin)、加权(weighted)、故障转移(failover)
- **Key 管理**：AES 加密存储 API Key，仅显示前缀；支持设置权重/优先级/专属售价入出/成本入出
- **连通性测试**：单 Key 测试，5s 超时
- **与通道关联**：供应商模型映射编辑通道时，可关联资源池（`keyGroupId`），系统自动按策略轮询 Key 并沿用专属价格计费
- **数据隔离**：每个 API Key 独立计费（`api_keys.quota_balance` 余额式扣减）
